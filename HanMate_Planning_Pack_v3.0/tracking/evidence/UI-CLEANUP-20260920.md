# 收藏、学习及设置界面简化 · 2026-09-20

用户希望收藏、学习等界面更简洁；沿用“先不调试”，只修改展示/导航和执行构建，不启动或安装应用。

## 已实施

- 收藏：顶部保留收藏夹切换及更多菜单；新建/编辑/删除/上下排序/刷新收进菜单，默认夹保护及删除确认保留。内容改为CollectionView列表，整行按钮打开阅读，每条更多菜单提供阅读/选择收藏夹；来源异常状态仍显示。50条分页规则保持，仅多页时展示翻页操作。
- 收藏归类：文件夹名称可换行、复选框有名称语义，保存固定在底部；保留刷新、并发版本检查和取消不保存。
- 学习首页：去除重复大标题、你好占位卡及常驻已就绪提示，突出词语/课文/语法/诗词与新建草稿；窄布局单列、480逻辑像素以上双列，失败仍有提示。
- 学习列表：整行阅读卡、轻量筛选工具栏、按需展开筛选与清除，结果计数保持在有界筛选视口之外，空结果独立显示；只有多页才显示分页。
- 设置：语言、学习资料、语音与发音、数据与隐私分组，7个功能入口全部保留，替换同权重的大色块按钮为中性导航行。
- 统一浅/深色背景、边框、次要文字、圆角及按钮样式。导航使用真实原生Button承载焦点/键盘/语义，非纯手势容器；文案12个新键均有中日英，系统字体缩放未禁用。UI入口字符串来自LocalizationService。
