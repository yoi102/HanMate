# 字典详情与离线释义注音 · 2026-09-20

## 实现

接入pypinyin 0.55.0导出的89,034条字/词读音（MIT），由独立C#展示注音器离线调用。Python仅用于构建数据；运行时不联网、不上传释义，不增加Python运行依赖。16条上下文/轻声覆盖修正轻轻地、认真地、玻璃等读法；自动结果仍须校对。未知字保留空白，不猜读音。

字典详情采用独立页面：词头、拼音、小朗读图标、单字部首笔画、释义和用法例句。移除阅读器的大工具区和分页，支持拼音显隐。压缩重复空行；超过240元素的释义先展示120元素，可展开全文。原始内容、稳定ID、人工注音、用户录音与数据库不修改。文字搜索、手写字词、拼音例词长按均进入同一页；可编辑个人词条通过更多菜单进入原管理页。

先用来源例句和明确标注的用法，再以75条原创辅助例句补充70个常用字词；不声称覆盖默认词库全部292,114词。例句中目标字词及其拼音红色加粗、不加下划线；重复命中及Unicode文本元素安全处理。例句和新注音算法纳入内容审核清单，共767个待审核对象；均未冒充出版社内容或正式终审。词头朗读复用所选离线AI声音，可编辑内容优先匹配原录音。
