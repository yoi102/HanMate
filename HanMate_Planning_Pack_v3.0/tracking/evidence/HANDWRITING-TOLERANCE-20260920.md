# 手写首次加载、连笔与越界保留 · 2026-09-20

用户要求优化首次出候选、放宽识别，并补充“子连笔易错”和“超出田字格松手整笔消失”。本轮沿用已授权的vivo真机调试，不更改45/48、原176聚合NOT RUN或82条执行账目。

## 实现

- 将原9,574字JSON解析、采样和特征计算提前为构建产物 `Handwriting/templates.bin`。运行时直接读取已准备的数组；进入搜索页即后台加载模板、字典索引及课程，不等待第一次抬笔。手写激活不再排在课程安装/索引初始化之后。
- 保留抬笔先显示六字、100ms后补词与点击直接查词。例词查询页缩至实际需要的6项，最多缓存64个候选行；按真实数据epoch校验，启停/修改后重查。新笔/撤销/清空/离页继续取消旧请求。
- 保留标准笔顺与未写完前缀匹配，增加顺序无关的一对一笔画匹配，允许单笔方向颠倒。以低成本下界选48个模板再做最小成本分配，不对全库运行昂贵匹配。
- 临近端点的断笔最多尝试两种合并。连笔允许最多少两次抬笔，将一条轨迹对应连续2—3个模板笔画；限12画以内完整字形。没有把少写笔画直接视为匹配，不承诺任意草书或多字连写。
- 田字格外采样限制到边缘，松手提交已写笔迹。原生越界Cancel同样保留可见笔迹；显式离页仍取消未提交笔，撤销/清空保留。不是缩小触控区来掩盖问题。
