# Windows/Android内部开发技术基线

依据D3/D6/D7分平台证据和ADR-105/106锁定当前路线。版本实值见environment-lock.json及NuGet locks。iOS没有因托管编译而获得原生通过，本轮排除。

| 领域 | 已选路线 | 已知限制与替代处理 |
|---|---|---|
| UI与Ruby | .NET10 MAUI、原生Ruby成组排版、分页阅读 | 已有长文/混排/字号证据；完整读屏与新字典性能后置，不退回空格拼版 |
| 注音与查询 | 离线候选＋人工锁定；独立只读默认词库；ContentDocument为真源 | 候选不等于终审；未知读音保留未知，不为匹配声音改错拼音 |
| 存储 | SQLite schema2、投影与版本守卫、导入操作收据 | 不覆盖真库；高版本或不明库拒绝，先保留数据 |
| 音频 | 单PlaybackCoordinator会话；本地WAV；系统解码MP3/AAC-LC M4A | 不支持的容器变体明确拒绝；默认音轨核对正文/读音哈希；Windows未打包清单随输出和publish复制 |
| 合成 | 可下载固定AI模型本地合成；显式系统语音回退 | 普通全文不承诺人工拼音控制；Android无可用普通话时提示，不改用英文或自动下载 |
| 文件与迁移 | 系统选择器、流读写、严格包验证、冲突另存和安全副本 | 自定义后缀可另存zip；取消不报成功；云同步/分享送达由提供者决定 |
| 依赖与交付 | global.json稳定SDK；中央包版本和锁文件；串行构建，源码/产物哈希 | 没有Git元数据则用完整快照；开发证书与正式签名分开，不变更现有身份 |

W0-02—05已有技术可行性证据，W0-06可在此内部范围锁定。HM-D019、内容/许可、发行身份、完整访问性/路由/压力/回归继续单列；没有用排除iOS或内部交付来填充这些测试的PASS。
