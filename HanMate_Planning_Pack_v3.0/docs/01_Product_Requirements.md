## 2. 页面与交互底线

主导航五个：拼音、学习、搜索、收藏、设置。学习四类切换顺序为**词语→课文→语法→诗词**。Windows 保留鼠标/键盘路径。列表点击正文进详情，独立播放按钮只播放；返回保留筛选、查询和位置。

拼音表按声母、韵母、整体认读等在同页分组。长按四声弹窗显示四个真实例词，目标拼音局部标红；声母通过完整音节说明声调，不把声母本身当四声。

词语大字与带调拼音对齐，例句整句播放。课文/诗词逐字注音，点段放大并到标点边界停止；整篇音频没有时间轴就不能假装可精确按段定位。

语法有独立详情，不用空课文页面代替：句型结构、中文解释、正确例句、可选注意事项。句型中的“主语”“地点”等占位符不是要背诵的例句，不默认进入朗读队列。

## 3. 添加与删除的具体语义

| 对象 | 添加 | 删除 |
|---|---|---|
| 个人词语/课文/语法/诗词 | 新建、TXT 输入整理、分享包导入 | 确认后删除本条，列出收藏和音频影响 |
| 内置或安装包中的单条内容 | 安装包或从“已撤下”恢复 | 默认撤下该条并持久化，不改包源文件；可恢复 |
| 学习资源包 | 导入 `.hanresource` 或应用随附安装 | 卸载；默认保留受收藏/用户录音引用条目快照 |
| 查词字典 | 导入 `.handict`；至少提供一套预置基础字典 | 禁用或卸载；其他字典与自动注音继续可用 |

“撤下”会真实移出普通学习/搜索结果，并持久化；不是 UI 上暂时隐藏到重启又出现。内置文件随应用分发时不能承诺卸载即可缩小安装包本体，容量页区分安装包资源、可清理数据和保留快照。

## 4. 数据与分享边界

个人内容保留原文、人工拼音和录音。分享内容包仅含用户选中条目、必要上下文、可选音轨与来源；没有设置、收藏夹、其他字典或其他录音。单音频分享不要求接收者安装应用，但不携带可编辑拼音。完整备份才包含全局设置、收藏及资源启停/撤下记录。

无授权的第三方全文/音频不因“分享”按钮存在就可导出；许可缺失需提示，允许导出自己有权分享的独立录音。首版不建设好友、社区或服务器。

## 5. 默认内容规模与非功能要求

正式初始目标建议为 **100 个词条、6 篇短课文、12 个语法点、6 首诗词，以及至少 1 套可管理的基础查词字典**。这些为可调整目标，不代表已收集、已授权或已审校；词条可以来自同一许可素材，但学习资源和字典资源的拥有关系不能混淆。

长文/音频/包大小限额见 specs；所有限制需预检，不能静默截断。一次只播放或录音一个任务。删除、覆盖恢复、更新源数据有影响预览与安全确认。测试状态和完成定义见 19、29。
