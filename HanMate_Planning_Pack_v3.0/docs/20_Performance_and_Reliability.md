# 20 · 性能、容量与可靠性设计

> HanMate 文档包 v3.0 · 2026-09-14 · 状态：开发基线提案，非已实现报告。
> 正式名称：HanMate / 汉语小伴；R01—R22 为需求基线，其余明确标注的规则为可调整默认设计。

## 1. 目标的性质

以下为首轮工程目标，不是本次文档生成时的实测成绩。M0 记录参考 Android 手机、iPhone 和 Windows 设备，注明 CPU、RAM、系统、Release 构建、词库规模、音频来源和冷/热启动。设备未锁定时不承诺所有低端硬件均达到相同数值。

| 项目 | 初始目标/测试口径 |
|---|---|
| 搜索 | 10,000 词条，数据库查询到结果 DTO 的 P95≤200 ms；另报含 250 ms 防抖的用户等待 |
| 长文 | 20,000 文本元素可打开、滚动、改音，无一次性创建全部原生 Label 导致的卡死 |
| 注音 | 不阻塞 UI；开始后有真实阶段状态，可取消；分别记录 1k/5k/20k 耗时和峰值内存 |
| 录音 | 20 分钟或 100 MiB 先到者安全停止；实际时长与采样格式记录 |
| 导入 | 对 10/100/500 MiB 样包记录吞吐、峰值内存、临时空间与取消延迟 |
| 列表 | 使用虚拟化，加载更多不重复或遗漏，不把全部音频字节装入 VM |
| 音频 | 新请求替换旧播放，不叠音；记录可听首音延迟，不能用 API 返回时间代替 |

## 2. 复杂度预算

注音词典用前缀索引/Trie 等确定实现，按最大词长限制扫描；不为多音字生成指数级候选组合。编辑差异匹配设置工作量上限，超限退化为保留原文并要求局部复核，不执行无限制二次方 diff。

分段、范围映射与哈希尽可能顺序扫描；长文可按可视区域缓存布局，但不破坏语义片段。文本换字体/宽度时，缓存键包括字体、字号、宽度、拼音可见性与内容修订。导航回来可以复用缓存，恢复备份/语言改变必须精确失效。

搜索前缀与包含匹配分开计量：普通 B-tree 并不能让前导通配符查询自动变快。先测 SQLite 查询计划，再决定额外投影或全文索引，不为小词库默认引入重型外部搜索系统。

## 3. I/O 与空间预算

导出先预估已保存资料和必要音频闭包；正式文件采用不可变存储和租约。空间预算至少考虑旧数据、安全备份、暂存解压、待安装新音频、SQLite 日志和保护余量。空间不足在破坏性步骤之前失败，不先删掉旧音频腾位置。

流式读取不是“完全没有内存风险”：单篇 JSON、深度、字符串长度、条目计数都要独立限额。一次把整个 512 MiB 包读入 byte[] 不合格。集中配置见 `specs/limits.json`，产品上限和防攻击上限分别说明。

## 4. 并发和维护门

录音、全文播放、导入恢复、编辑保存分别使用适当的操作锁，不拿一个覆盖全应用的长时间 UI 锁解决问题。恢复执行时进入数据维护门，停止关联播放、处理未保存草稿，拒绝新写入；导入预览阶段仍可阅读，提交前校验 dataEpoch。

背景计算结束必须核对当前内容 ID、修订号和请求 ID；不能把旧页面的拼音或搜索响应写到新页面。文件 GC 与导出/播放的文件租约相互协调。

## 5. 可观测性

本地结构化诊断只记 operationId、errorCode、elapsedMs、itemCount、byteCount、platform、buildVersion，不默认记原文或录音。用户主动导出诊断前预览内容；捕获未处理异常应尽量保留草稿和恢复标记，但不承诺进程硬终止仍能运行清理代码。

性能结果记录 P50/P95/最大值、运行次数、预热方式、失败次数和原始日志。参考每项至少 30 次可重复操作，耗时较长导入按合理样本单独说明。不仅截取一次最快结果。

## 6. 压力与恢复测试

连续执行 100 次音频切换、100 次打开关闭阅读器、50 次录音试听保存/取消、多次导入同一包，观察句柄/订阅/文件数是否持续增长。休眠唤醒、语言循环切换、窗口缩放、手机旋转与键盘弹出同时测试。

启动恢复只依据数据库收据和可验证文件状态判断操作是否提交，不依据一个可能滞后的布尔标志。孤立文件清理有保护期与审计摘要；恢复失败不清空整库。


## 7. 可安装字典与语法容量

保留10,000词查询P95目标，新增合并100,000词的规模验证目标；未测设备不承诺同等200ms。最多100个安装资源、单包10,000条、语法最多20条例句/40个结构单元为初始保护值，集中记录 limits.json。

测量启停对查询更新的延迟、资源更新索引事务时间、引用快照增加的占用、备份展开峰值。不能每次进入学习页重新扫描全部包并重新注音；不可变内容指纹可缓存，用户修改和资源版本变化时失效。

卸载显示实际可释放与仍被保留的音频容量，不能将逻辑删除数量直接当回收磁盘字节。备份预估同时计算资源、用户录音和安全备份的空间。
