# 00 · 项目总体规划

> HanMate · 汉语小伴 · 文档 v3.0 · 2026-09-14
> 正式产品名已确认；这是开发规格与数据契约，不是已实现或三平台测试报告。


## 1. 产品定位

**HanMate（汉语小伴）**是离线优先的中文学习与个人资料应用。框架继续使用 **.NET MAUI**，目标为 **iOS、Android、Windows**。没有因先前比较其他框架而改成 Flutter；产品名已经确定，图标、应用标识、商标与商店重名核查仍是独立发行事项。

固定五个主入口：**拼音、学习、搜索、收藏、设置**。学习页有**词语、课文、语法、诗词**四种类型，不新增“语法”第六个主导航。界面语言简体中文、日语、英语；教学中文和带调拼音始终保持，日英辅助译文按设置显示，中文界面隐藏译文及留白。

## 3. 首版边界

| 能力 | 首版必须具备 | 暂不默认增加 |
|---|---|---|
| 学习 | 拼音表/四声；词语、课文、语法、诗词；按场景/难度/学段分类 | 语音评分、自动出题、学习社交 |
| 创作 | 手工新建、粘贴/TXT、离线注音、人工改音、可选译文 | PDF/Word/OCR、自动翻译、云 AI |
| 音频 | 本地播放、设备 TTS 回退、录音、导入、片段绑定 | 自动时间轴、剪辑台、后台连续录音 |
| 资源 | 预置四类内容；本地学习包/字典包安装、禁用、卸载、更新 | 在线商城、支付、用户上传社区、下载排名 |
| 保存 | 搜索、收藏夹、设置、内容分享、完整备份恢复 | 账号、云同步、跨用户实时协作 |

“以后可下载”不代表现在要创建服务器，也不代表现在可只放一个无效下载按钮。现在必须完成资源安装和卸载规则；将来下载到文件后复用相同验证/安装服务。

## 4. 内容、资源、字典不是一个概念

`LearningContent` 是一条词语、课文、语法或诗词。`LearningResource` 是管理多条内容及其音频的一套可安装资料。`DictionaryResource` 是只含 word 词条的查询资源，默认不在学习主列表中混入数千个词。个人词条与学习包里的 word 也可参与查词。

**查词字典 ≠ 自动注音引擎的基础字音词典。** 用户卸载所有查词字典后，文本自动注音仍可用，人工校正也不丢失。详细规则见 [字典管理](32_Dictionary_Management.md)。

## 5. 完整用户闭环

```text
选择界面语言 → 拼音与四声 → 按分类学习四类内容
→ 搜索词语 → 收藏 → 导入自己的文字 → 校正拼音 → 配录音
→ 分享单条/多条资料或录音 → 安装/管理学习包和字典
→ 导出备份 → 另一设备离线恢复
```

删除包前展示收藏、录音、草稿引用。默认保留受引用条目的只读快照及用户录音，并从学习/字典普通列表撤下；彻底删除用户依赖必须另行明确确认。卸载不是无条件清空相关数据。

## 7. 完成标准与证据

内容正确、字音对齐、播放可控、人工修改不丢、删除不误伤、备份可迁移。框架能构建不等于音频可用；有 JSON 文件不等于完整字典；文档自检 PASS 不等于应用验收 PASS。

R01—R22 每项必须映射到实现文件和验收记录。未执行写 NOT RUN，缺环境写 BLOCKED，不能把理论支持写成 PASS。正式素材的正文、拼音、译文、录音和来源分别审核，AI 不得虚构审核者或授权。
