# 19 · 测试策略与验收标准

> HanMate 文档包 v3.0 · 2026-09-14 · 状态：开发基线提案，非已实现报告。
> 正式名称：HanMate / 汉语小伴；R01—R22 为需求基线，其余明确标注的规则为可调整默认设计。

## 1. 验收层次

测试分为纯逻辑、持久化集成、平台适配、端到端、内容质量五层。Mock 播放器只证明调度正确，不能证明真机发声；JSON Schema 通过只证明部分数据结构，不证明恢复功能已实现；代码编译通过不能替代三平台实际运行。

所有应用用例初始状态为 **NOT RUN**。允许 PASS、FAIL、NOT RUN、BLOCKED 四种结果。BLOCKED 必须写明缺少什么环境/素材，不能当作通过。文档包自检单独记录，不混进应用完成率。

## 2. 测试输入和基准

版本化保留：示例 ContentDocument、文本元素范围、拼音转换表、分段预期、搜索候选、故障包、数据库旧版本快照。测试基准变更要记录原因和审查，不得把实现输出自动写成正确答案。

基础语料覆盖银行/行走、音乐/快乐、轻声、ü、隔音符、长无标点文本、诗行、CRLF、Emoji、组合字符与未知字。词典语料的准确率报告必须说明样本量与人工标注来源；没有基准时不写“准确率 99%”。

## 3. 各层必须验证什么

| 层次 | 核心验证 | 证据 |
|---|---|---|
| 单元 | 标调、规范化、分段守恒、注音锁定、语言选择、状态机 | 测试名称、断言、运行日志 |
| 集成 | SQLite 约束、迁移、索引重建、导入映射、文件回滚 | 临时库、前后快照、测试日志 |
| 平台 | 录音、中文 TTS、文件选择保存、权限、输入法、生命周期 | 设备/系统/构建号、实际操作结果 |
| 端到端 | 导入→改音→录音→收藏→导出→另一平台恢复 | 内容及文件哈希、录屏/试听记录 |
| 内容 | 拼音/例句/译文/示范音频一致性、来源 | 审核表和真实审核者 |

## 4. 跨平台矩阵

iOS→Android、Android→iOS、iOS→Windows、Windows→iOS、Android→Windows、Windows→Android 六个方向分别执行完整备份恢复。另测各平台自身恢复、不同应用版本的支持范围以及相同包重复导入。

每次恢复至少包含：两个收藏夹、一个词条、一个课文、一个人工锁定读音、一条整篇录音和一条片段录音。同一音频多引用、没有内置目录音频、名称冲突、内容 ID 冲突另建测试包。

## 5. 故障注入点

在暂存文件写到一半、哈希验证后、正式音频安装后、数据库事务开始前、事务进行中、COMMIT 后但清理前、收据已提交但外部操作日志未更新时分别终止进程。检查旧数据完整或新数据完整，不能出现“数据库有引用但正式音频不存在”的半成功。

磁盘不足、权限拒绝、系统取消、录音中断、数据库忙、损坏 JSON、过大 ZIP 分别测试。测试失败不得自动清库“修好环境”；先保留失败样本。

## 6. 通过门槛

所有 R01—R22 有对应实现与用例。所有 P0 用例 PASS 后才能声明首版完成；未执行平台验证可以交付阶段成果，但不能声明该平台正式完成。数据丢失、错误覆盖、路径逃逸、静默上传、隐藏录音、错误音源冒充示范均阻断发布。

默认把功能完成率、用例执行率、执行通过率分别展示：未执行不计入通过；一条用例在 Windows PASS 不代表 iOS PASS。性能目标的调整需附设备实测，不通过删除核心内容来达标。

## 7. 用例与原版映射

可执行用例清单见 [29 · 验收用例](29_Acceptance_Cases.md) 和 `tracking/acceptance-cases.csv`。沿用原版 R01—R22 需求身份，新用例 HM-Txxx 细化旧 A01—A42 的场景；旧编号留在 archive，不要求机械保留一个大用例对应所有异常。

执行记录另存 `tracking/TEST_MATRIX.md`，字段包含 testId、platform、device、OS、appCommit、result、evidence、issueId、executedAt。预期结果与执行记录分离，方便同一用例反复回归。


## 8. v3 新增回归范围

保留原 HM-T001—HM-T128；新增 HM-T129—HM-T176，分别覆盖语法12项、资源生命周期12项、字典12项、分享与协议迁移12项。应用用例仍全部 NOT RUN；只有文档与夹具校验实际执行。

增加资源/字典组合测试：同字不同音、来源开关、卸载最后一部查询字典后自动注音、收藏和用户录音快照、同版本篡改包、更新条目跨版本、grammar 引用冲突重映射。既有备份六方向测试还须加入资源启停/撤下和语法数据。

文档校验器验证当前 SQLite 目标结构，不能代替旧用户库迁移；旧包夹具内存转换不能代替实际跨平台导入。正式内容审核不能由这类自检自动标为 approved。
