# 24 · 用户使用说明与常见问题草案

> HanMate 文档包 v3.0 · 2026-09-14 · 状态：开发基线提案，非已实现报告。
> 正式名称：HanMate / 汉语小伴；R01—R22 为需求基线，其余明确标注的规则为可调整默认设计。

## 1. 首次使用

在设置中选择简体中文、日语或英语。界面按钮会切换语言，学习用的汉字和拼音保持不变；中文界面不显示日/英辅助译文。首次可先点拼音表的条目试听，确认设备音量和可用音源。

本手册描述计划中的成品行为，供实现和文案校对使用，不表示应用现在已发行。

## 2. 拼音与学习

首次打开拼音页会出现四步引导，只有当前目标保持明亮，箭头和文字指向你需要操作的地方：先单击拼音听读音，再长按进入例字例词页；接着单击例字听读音，最后长按例字查看字典释义。直接操作页面上的高亮目标即可推进，也可以随时跳过。完成后不再自动弹出，点第一分组右侧的“？”可以重看。Windows长按操作也支持右键或聚焦后按F10。每行例词点击朗读整个词，红色加其他强调标识指出当前学习的拼音部分。

学习页选择词语、课文、语法或诗词，再按场景、难度、学段筛选。词语详情上方是带调拼音，下方是汉字；点例句听整句。课文点一个小段会放大并只读该段，只有选择全文朗读才继续下一段。

## 3. 搜索与收藏

搜索框位于页面底部，可输入“你好”、`nihao`、`nǐ hǎo`、`ni3hao3`。`ü` 可用 `v` 或 `u:` 输入；普通 `u` 不等于 `ü`。搜索范围是已收录词条，不是联网万能词典。

点收藏按钮选择收藏夹；同一内容可放进多个夹。删除收藏夹只移除这个夹的关系，不删除原课文和录音。删除个人正文则会提示它关联的收藏和声音，确认前应检查或备份。

## 4. 导入自己的资料

从学习页新建/导入，粘贴文字或选择支持编码的 TXT，预览后选择类型与标题。应用自动注音，但人名、古文和多音字仍需检查。没有译文也可以保存个人内容，不要求先联网翻译。

进入注音编辑后点具体字音修改，支持带调或数字拼音。锁定的校正在再次自动注音时保留；修改原文可能使部分校正与录音需要重新确认。

## 5. 录音和分享

选择整篇或具体片段，开始录音、停止、试听，再保存。首次使用麦克风需允许权限；拒绝后仍能阅读和使用已有声音。自己的跟读录音不会默认替换内置标准示范。

分享音频得到普通音频文件；分享学习内容包得到正文、注音和选中的音频。分享包不含全局设置和其他收藏夹。发给别人前检查预览，因为声音可能包含个人信息。

## 6. 换设备

在设置中导出完整备份，保存到自己可找到的位置，复制到新设备后导入。完整备份包含已保存个人内容、改音、用户音频、收藏夹和可迁移设置；未保存草稿应先保存。不要以为导出文件仍留在应用私有缓存就能在卸载后找回。

默认合并保留现有内容；完全替换需要确认并先制作安全备份。相同 ID 但修改不同会保留双方，不按设备时间自动覆盖。新设备的系统语音可能不同，需要重新选择普通话语音。

## 7. 常见问题

**为什么改了拼音，声音没改？** 显示注音和音源是两件事。系统朗读和当前离线AI声音都不保证接受逐字改音；请绑定核对后的录音，并检查“需复核”提示。

**为什么导入一整篇录音后，点某句没有播放其中一小段？** 首版不自动生成时间戳。整篇音频用于全文播放，单段需独立音频、已启用的离线AI声音或明确选择的系统语音。

**没网还能用吗？** 已有正文、搜索、收藏、离线注音和本地音频可用。应用已内置AI语音包，新安装默认可在本机离线朗读支持的中文。系统合成是否离线可用取决于设备语音配置，两种语音设置独立。

**为什么四声有的行没有例词？** 不为凑齐四行编造词语。没有适合的已核对常用例词时会明确说明。

**备份加密吗？** 首版文件默认不加密。请只存放和分享给可信对象，文件后缀不是保密措施。

**为什么导入失败？** 查看错误说明。格式版本、损坏文件、校验不符、空间不足或容量超限都可能被拒绝；失败不应破坏原有资料。保留原文件，不反复重命名扩展名尝试绕过校验。


## 8. 新增使用说明

**在哪里学语法？** 学习→语法。句型是结构提示，点击下面的真实例句朗读；中文界面仍显示中文解释，不显示辅助翻译。

**如何加/删资料？** 学习→新建/导入创建个人词语、课文、语法、诗词；管理内容可安装学习包。个人资料删除前确认，包条目可撤下/恢复，整包可卸载。

**如何加字典？** 搜索→字典→从本地导入 `.handict`；启用后参加查询，可排序/禁用/卸载。不是任意网上字典格式都能导入。

**删字典会让自动拼音消失吗？** 不会，自动注音的基础数据独立。收藏过或绑定自己录音的条目默认保留快照，其他字典和个人词条仍可查询。

**分享给别人怎么打开？** 内容包由对方安装 HanMate 后导入；单独音频可用支持格式的播放器听。内容包不含你的全局设置和其他录音。自己换机请选择完整备份，注意预览是否提示部分资源未包含。

**是否已提供在线下载？** 学习资源/字典仍通过本地包安装；AI中文语音包随应用提供，可在设置中离线恢复缓存。没有学习资源商城或账号系统。

## 9. 内置声音与字典点读

设置→朗读声音可选择MeloTTS、Kokoro或系统文字转语音，再选音色试听。MeloTTS为默认，提供官方中文女声（44.1kHz）；Kokoro提供中文男女声（24kHz）。两模型和前处理数据共约376MiB，随应用提供，可离线使用。Melo中文男声仍在寻找合适来源，当前没有该音色，不用变调冒充。

点击字典词头、释义段落或例句开始朗读；同一处还在准备或播放时再次点击就停止。点另一处会先停止并清理旧声音，再读新内容；离开页面停止。底部显示准备/失败原因，不需要播放图标。拼音及例字例词仍优先原录音，缺完整录音时由Melo按课程标注读音补充。

系统语音使用设备上已安装的普通话音色，选中后即可用于字典和正文，不会每段重复确认。没有可用声音时给出提示，可在系统设置中安装普通话音色或改选内置模型；系统读音不遵循手工拼音。

模型准备失败可重试；管理当前语音包中可恢复或清除缓存。清除只影响该包解包副本，不删除正文、收藏和录音，另一模型也不受影响。旧版启用的AISHELL会迁移到Melo默认音色；原来停用/移除的选择保留。模型和本机音色ID不进入个人备份。

遇到不支持的英文、表情或生僻字时，内置模型会在朗读前提示，不能把跳过内容当成成功。多音字和教学听感仍需核对；采样率或非静音检查不代表真人听审已通过。
