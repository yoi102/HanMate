# 33 · 内容与录音分享详细设计

> HanMate · 汉语小伴 · 文档 v3.0 · 2026-09-14
> 正式产品名已确认；这是开发规格与数据契约，不是已实现或三平台测试报告。


## 1. 分享是文件交付，不是社交平台

首版支持系统分享与另存文件，不需要登录、好友、服务器或公开社区。内容选择明确，发送由用户发起；系统分享面板返回不能证明对方已收到。录音可能识别个人，预览说明文件包含自己的声音。

## 2. 分享矩阵

| 用户选择 | 输出 | 包含 | 不包含 |
|---|---|---|---|
| 一个词语 | `.hanpack` | 词头、释义/例句、拼音、译文、被选音轨、来源 | 其他词、全局设置 |
| 一篇课文/诗词 | `.hanpack` | 原文、分段、人工拼音、被选录音、来源 | 整套资源或其他录音 |
| 一个语法点 | `.hanpack` | 句型结构、说明、全部必要例句、校正、可选音轨 | 与其无关的其他语法 |
| 多条混合内容 | 一个 `.hanpack` | 用户勾选四类内容的并集及依赖 | 未选收藏夹/字典管理信息 |
| 单条自己录制的音频 | 原音频文件 | 可播放的实际声音文件 | 正文、可编辑拼音、个人设置 |
| 自己换机 | `.hanbackup` | 已保存用户资料、收藏、设置、可备份资源状态/数据 | 权限、设备路径、临时缓存 |

后缀选择受平台选择器影响时可用 ZIP 回退，文件内 manifest 才决定类型。多条分享不是自动公开资源商店发布。

## 3. 入口与 P15 预览

四类详情更多→分享；学习/收藏列表多选→分享所选；音频管理→分享此录音。P15 显示条目类型/标题、音轨清单、文件预估大小、许可限制、未保存变更、当前将排除的内容。

默认选中正文和已保存拼音；日英译文随内容数据一并携带，不根据发送者当前 UI 删除另一语言。发送者 UI 中文隐藏译文，只影响显示，不意味着备份或分享要丢弃它们。

默认不自动勾选所有用户音轨，可选“当前使用音轨”“我选择的音轨”“不含音频”；确切默认由用户预览确认。不得把录音列表中的其他私人音轨顺带打包。

## 4. 单条与多条包闭包

以完整 ContentDocument 为首版最小内容单位，不做任意字符范围截取。选择片段录音配文分享时，说明会包含所属完整词条/课文；只想发声音则选单音频路径。避免单段缺上下文、语法 unitId 悬空。

多个条目共享同一音频哈希，字节只存一次，asset/binding 逻辑引用完整保留。过滤未选音轨时连同它的 preference 一起移除。grammar 字段引用的说明/例句不能被过滤掉。

## 5. 隐私白名单

content 包只有 manifest、contents、audio/index 和已选音频文件；不得带 settings.json、collections.json、resources.json、搜索历史、设备 voiceId、麦克风权限、真实文件路径、调试日志。

资源词条分享后作为 personal 导入；source 中保留出处，接收方不能用这个包卸载、更新或启用源资源。公开包里的“author”“approved”“builtin”都是来源声明，不是写入特权。

## 6. 许可和内容完整性

用户需具有分享所选文本、译文、音频的权限；四者可以有不同来源，不能只看代码许可证。缺许可/禁止再分发时禁用受限载荷，展示具体项。分享自己的录音不自动获得配套第三方全文的再分发许可。

被禁止的教学正文不能通过快照包绕过。允许只分享本人有权分享的独立录音；若删去受限载荷使内容包不再能通过结构/引用校验，应拒绝生成该内容包，而不是制造残缺文件。

## 7. 音频分享细节

录音先停止并写完容器，再生成可分享文件；不能导出仍写入的流。保持真实 container/codec 与后缀，不改名伪装 MP3。文件名使用安全标题片段加短 ID，不暴露原设备私有路径。

单音频若删去应用内关联信息，接收方只能听声音，无法自动恢复注音/片段关系，预览必须说明。多个音频首版优先跟内容包一起发；单文件直接音频分享一次选一条，避免不一致的多文件平台行为。

## 8. 操作状态与文件生命周期

选择→检查权限/来源/未保存草稿→固定数据快照和音频租约→生成私有临时包→重新校验→系统分享/另存→记录操作状态→安全期限后回收临时文件。

结果枚举：Exported、Saved、ShareSheetOpened、Cancelled、Failed；不返回“对方收到”。关闭分享面板不能立即删除系统仍可能读取的文件；临时分享区受配额限制，清理只影响临时副本，不删原录音。

## 9. 接收方导入

收件后从 HanMate“导入内容包”选择文件，预览→校验→ID 冲突处理→保存个人内容→打开对应详情。没有自动翻译、自动改音或自动覆盖本机同标题条目。

重复相同包幂等；同 contentId 不同语义保留双方，全图重映射 content/unit/segment/token 与音轨。grammar 内的 unitId 引用也属于重映射范围。没有音轨则正文仍可学，普通话 TTS 可用性仍按设备检查。

## 10. 与备份、资源安装的分流

`.hanpack` 是选中资料分享；`.hanresource/.handict` 是安装资源；`.hanbackup` 是全局迁移。选择到另一类型时应清楚跳转到正确预览，不默默当同一种包处理。分享包永远不能触发“替换全部用户数据”。

## 11. 验收

四类单条、多选混合、仅本人录音、选择音轨过滤、中文 UI 不丢日英数据、许可阻断、无隐私额外文件、取消保存、接收后可编辑、grammar 引用重映射。HM-T165—HM-T176 含迁移边界测试。真实平台分享、实际录音和音频迁移仍须在应用中执行。

## 12. 当前实现与剩余范围 · 2026-09-18

正式详情可预选当前整条内容，文字草稿列表提供统一多选入口；50条分页，选择跨页保留，最多导出100条。预览固定已保存图、标题及排除的音轨/草稿数量。只输出正文、人工拼音、译文和出处，音频索引为空；含音轨选择、大小估算、学习/收藏列表直接多选、系统另存文件继续待实现。

来源声明CanShare=true时允许导出；来源限制不能由勾选绕过。仅SourceId=personal、Reference=User input、NOASSERTION且无ResourceId的原始个人输入，允许用户明确确认文本及译文分享权利。该确认只在导出快照写入CanShare及permissionNotes，不改本机来源，不提升CanDistribute，不伪装独立版权审查。资源编辑副本仍受原来源限制。

已保存user来源PCM16 WAV可独立分享；停止播放后核对当前目标、真实WAV与SHA256，持有export租约直至复制结束。导入音轨和标准音轨没有本人录音分享入口。needsReview录音允许仅分享声音，关联状态保持待复核；不把它包装为匹配正文的音频。

临时副本使用share-GUID安全文件名，失败删除.part、成功关闭后改名。单文件100MiB、私有分享区256MiB、生成后7天可回收，系统可能提前清缓存；过期清理只处理本服务生成的副本。关闭分享面板不立即删文件。按钮只打开系统面板，不自动选择联系人或上传，状态只表示已调用分享。

Android16/API36模拟器Release已验证hanpack/WAV面板打开后取消，以及四类包导入、冲突另存和重复复用；无真实外发。Windows新交互/iOS原生、真机、含音频包、另存文件、完整备份与六方向迁移尚未验证或实现。详见tracking/evidence/W4-text-content-sharing.md，W4相关工作包保持IN_PROGRESS。

## 13. 当前随包录音选择 · 2026-09-18

上一节纯文字阶段已扩展为可选本人WAV录音。固定正文预览后打开独立录音选择页，每页10条，显示所属内容、目标文字、时长、字节数、默认/待复核状态；跨页选择保留，默认全部不选，可一键排除全部音频。返回显示选中/排除数量和文件字节合计（包内按哈希去重），改变正文选择或重新预览会清除旧音轨选择及旧导出文件引用。

仅已保存source_role=user、asset.origin=user的PCM16 WAV可勾选，生成含录音包前再次确认音频分享权利及声音隐私。第三方导入/标准音轨暂不能随包分享，不以文本来源许可推定音频权利。读取使用export租约和快照哈希校验，生成后重新严格读包；手工拼音和译文仍完整保存。

接收预览新增/复用音轨、待复核数和实际音频字节；导入标为imported，本机已有默认优先，待复核不能自动成为新默认。Android模拟器已通过原有17.4秒录音选择→随包生成→分享面板取消，以及工程WAV包冲突导入→重复复用→原生播放器完成。无接收者外发或真人声音采集。压缩音频、标准/第三方音轨权限、系统另存文件、完整备份及三平台完整验收仍待后续，见tracking/evidence/W4-audio-content-packages.md。
