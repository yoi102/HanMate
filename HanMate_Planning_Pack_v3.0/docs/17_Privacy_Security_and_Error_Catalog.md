# 17 · 隐私、安全与错误处理

> HanMate 文档包 v3.0 · 2026-09-14 · 状态：开发基线提案，非已实现报告。
> 正式名称：HanMate / 汉语小伴；R01—R22 为需求基线，其余明确标注的规则为可调整默认设计。

## 1. 隐私设计基线

应用首版不主动上传正文、搜索词、收藏、拼音校正、个人译文或录音到开发者服务器、云 TTS 或 LLM。没有账户不代表没有需要保护的数据：用户声音、个人文本和备份同样需要明确操作边界。

系统 TTS 由设备语音提供方实现，系统备份和用户选择的分享应用有各自行为。隐私说明必须区分“本应用没有上传接口”和“整个设备绝对不联网”。严格不调用系统合成时使用 localOnly 音频策略。

麦克风仅在用户发起录音时开启，界面显示状态与时长；进入后台不静默继续录音。使用文件选择器只读取用户明确选定的文件，不遍历无关私人目录。

## 2. 数据流和边界

| 输入/输出 | 信任级别 | 处理 |
|---|---|---|
| 用户输入/TXT | 不可信文本 | 限额、严格解码、按纯文本展示 |
| 外部 hanpack/backup | 不可信结构和文件 | 路径、schema、引用、哈希、容量与权限校验 |
| 导入音频 | 不可信二进制 | 有界探测、实际解码、隔离暂存 |
| 自带审核目录 | 应用发行源 | 版本/哈希验证；普通导入不能冒充 |
| 系统 TTS | 外部平台能力 | 用户可关闭；不承诺所有语音离线 |
| 内置AI语音包（ADR-108） | 应用随附的固定模型 | 包内读取、大小/SHA256校验后解包；首次使用和缓存恢复均无HTTP请求。正文、搜索词、录音和账号不上传。已有单独下载服务仅保留兼容/工具路径，应用配置使用本地资源供应器 |
| AI本机合成 | 已安装模型、用户所选声音 | 正文仅在进程内推理，生成WAV在内存中播放；不自动持久化音频、不上传或改变手工拼音 |
| 系统分享 | 用户主动外发 | 预览范围，私有数据不默认夹带 |
| 导出备份 | 含私人数据的普通文件 | 明确未加密，不作保密保证 |

自带资源可信只指来源渠道；内容本身仍需教学质量校对，不能以“在安装包中”代替读音审核。

## 3. 文件和权限最小化

只用应用私有目录存正式资料；系统文件交互通过选定文件的流。Android 文档选择框可基于 Storage Access Framework 授予用户选中文件访问，不默认索取全盘权限；具体 MAUI 包与系统版本仍按 M0 验证。[S16](27_References.md)

系统分享目录与数据库/完整缓存目录分开，Android FileProvider 只暴露专用导出子目录。MAUI 分享文档提醒不当的路径配置可能暴露更大范围文件；不可直接共享整个 AppData/Cache。[S07](27_References.md)

不申请摄像头、通讯录、定位或照片权限来完成本项目不需要的功能。平台用途说明按实际麦克风/文件能力填写，不照抄无关示例。

## 4. 日志规则

允许记录 operationId、错误码、阶段、耗时、字节数、实体数量、匿名化的本地诊断标识和版本。不记录完整正文、搜索输入、录音字节、绝对私人文件路径或导出包内容。

异常堆栈存开发/诊断通道并做路径脱敏；普通用户看到简明原因与恢复操作。用户主动导出诊断信息前先预览，默认不含个人内容与媒体。

日志自身按大小轮换，不能磁盘无限增长。哈希也可能用于识别内容，不默认把内容 SHA 上报服务器；首版无诊断上传接口。

## 5. 错误结果约定

正常成功：Success(data)。用户取消：Cancelled，无红色失败提示和错误日志。业务/平台失败：Failure(code, safeMessageKey, retryable, context)。UI 根据 code 本地化，不把 Exception.Message 直接当跨语言文案。

| 错误码 | 用户可见含义 | 数据保护 |
|---|---|---|
| CONTENT_NOT_FOUND | 内容已不存在或暂不可用 | 不建悬空收藏 |
| REVISION_CONFLICT | 内容已被其他操作更新 | 保留草稿，不覆盖 |
| TEXT_ENCODING_UNSUPPORTED | 当前编码不支持 | 原文件不动 |
| TEXT_INVALID_ENCODING | 文本解码失败 | 不替换成乱码后保存 |
| TEXT_LIMIT_EXCEEDED | 文字或文件超过当前上限 | 不截断 |
| TEXT_BOUNDARY_MISMATCH | 字符边界与保存注音不一致 | 不移动校正后强行导入 |
| PINYIN_INVALID | 拼音/声调格式不合法 | 保留输入待修改 |
| AUDIO_PERMISSION_DENIED | 未获麦克风权限 | 仍可阅读编辑 |
| RECORDING_BUSY | 录音中，需先停止 | 不丢弃正在录制的内容 |
| AUDIO_UNAVAILABLE | 当前没有适用音源 | 不读成错误语言 |
| AUDIO_STALE | 音频与修改后的文字/读音待核对 | 保留文件，禁止静默默认使用 |
| AUDIO_FORMAT_UNSUPPORTED | 此编码不能播放 | 不改后缀伪装转换 |
| AUDIO_DECODE_FAILED | 音频损坏或解码失败 | 暂存清理，正式资产不提交 |
| PACKAGE_VERSION_UNSUPPORTED | 包版本不支持 | 写入前停止 |
| PACKAGE_TYPE_MISMATCH | 文件内容与所选导入操作不符 | 不应用分享包的设置 |
| PACKAGE_PATH_UNSAFE | 包含不安全路径 | 不解压到正式目录 |
| PACKAGE_DUPLICATE_ENTRY | 包内有重复/歧义文件名 | 拒绝 |
| PACKAGE_JSON_DUPLICATE_KEY | JSON 字段重复 | 拒绝不同解析器歧义 |
| PACKAGE_HASH_MISMATCH | 包内文件校验失败 | 旧数据不变 |
| PACKAGE_REFERENCE_MISSING | 目标/音频引用缺失 | 不提交悬空关系 |
| PACKAGE_LIMIT_EXCEEDED | 包容量/深度/条目超限 | 流式停止 |
| PACKAGE_ID_COLLISION | 同包 ID 对应不同清单 | 不覆盖旧 receipt |
| PLAN_STALE | 预览后本机数据已变化 | 重新规划 |
| STORAGE_FULL | 空间不足 | 先保留旧数据与草稿 |
| DB_MIGRATION_FAILED | 数据升级未完成 | 不清库重建 |
| DB_WRITE_FAILED | 保存失败 | 事务回滚，保留输入 |

更底层未知异常映射为 UNEXPECTED_ERROR 并提供 operationId；不对未知情况自动重试破坏性动作。

## 6. 威胁用例

恶意 ZIP 路径、大小写重名、压缩炸弹、超深 JSON、重复属性、伪装 MIME、异常 WAV/MP3、包 ID 欺骗、内置身份伪造、半恢复、默认音轨跨目标引用、共享目录泄露均需要负例测试。

SHA-256 不是数字签名。首版不声称验证作者身份；外部内容自称 approved 不授予官方标志。备份默认无密码加密，不能将后缀隐藏视作加密。

## 7. 发布隐私材料

`templates/PRIVACY_NOTICE_DRAFT.md` 为可填写的应用隐私说明草案，必须按最终依赖、发行主体、联系方式和系统备份策略核对后发布。Apple App Privacy 和 Google Play Data safety 均需根据实际应用及第三方组件行为填写；不因“离线优先”就自动选择所有“不收集”。[S17 / S18](27_References.md)

首版目标包含低龄学习材料，但不自动声明适用于特定儿童专区或满足所有儿童隐私法规。实际目标年龄、发行地区和商店分类由发布前审核决定，不能让 AI 根据“小学标签”自行承诺合规。


## 8. 新增错误码与信任边界

| Code | 含义 | 处理 |
|---|---|---|
| GRAMMAR_REFERENCE_INVALID | 语法说明/例句跨内容或缺失 | 保留草稿，拒绝提交/导入 |
| RESOURCE_VERSION_COLLISION | 同资源同版本载荷不同 | 拒绝覆盖并显示来源差异 |
| RESOURCE_KIND_MISMATCH | 同资源试图改类型 | 拒绝，不能把字典变执行插件 |
| RESOURCE_ID_RESERVED | 外部包冒用受保护内置 ID | 拒绝，不以清单自称身份为准 |
| DICTIONARY_KIND_INVALID | 字典含非 word 内容 | 整包拒绝，旧字典仍可用 |
| RESOURCE_DEPENDENCIES_EXIST | 卸载涉及收藏/用户音频 | 影响预览，默认保留快照 |
| SEARCH_CURSOR_STALE | 来源变化使分页失效 | 重新查询，不混旧结果 |
| BACKUP_RESOURCE_INCOMPLETE | 许可/容量导致资源未携带 | 完整备份阻断，显式允许部分后带警告 |
| SHARE_LICENSE_BLOCKED | 所选正文/音频无分享权限 | 排除或阻断，不能产出悬空引用包 |

外来资源 manifest 是数据，不执行脚本、不启动下载、不授权覆写内置资源。当前仍不接入线上资源商店；后续下载需新增来源可信性与完整性审查，不能只检查 HTTPS URL 就认为合法素材。


## 9. 已落地的本机隐私行为 · 2026-09-18

Android Release不再声明INTERNET/ACCESS_NETWORK_STATE；只请求用户主动录音需要的RECORD_AUDIO。allowBackup=false，旧fullBackupContent与新dataExtractionRules都排除应用数据，含云备份及设备迁移。系统文件选择/保存不需要全盘权限。FileProvider仅允许cache/sharing，不能暴露整个缓存或数据库目录。

应用内隐私说明提供简中/日/英，说明固定句系统语音试听、无开发者上传接口、未加密备份、外部文件提供方与其他平台系统备份边界。移除音轨/放入回收站不等于物理擦除：旧媒体、安全恢复副本及部分临时文件保留，GC待实现。七天分享副本清理在生成新副本时执行，不承诺后台准时删除。UI异常诊断只写异常类型，避免把路径/原文随异常消息输出。

发行主体、联系信息、地区/年龄分类和商店数据表仍待实际审核；本地实现审计不将W5-04标DONE。

后续音频实现：阅读系统语音默认关闭，设置允许后仍逐次明确确认，只传实际缺失目标的中文正文，不传拼音、录音或整库。系统提供方的网络策略仍由设备控制，不能因应用无INTERNET权限而宣称提供方必然离线。压缩导入仅解码用户所选文件的私有缓存，M4A外部引用在调用系统解码前拒绝；规范化WAV沿用本地音频保护/备份，不上传原始MP3/M4A。


## 10. 当前双模型与系统音源选择 · 2026-09-20

ADR-111覆盖旧逐次确认规则：用户在“朗读声音”选择系统文字转语音后，字典及普通阅读缺录音目标可直接把当前目标中文交给设备语音提供方。音源及设备语音ID仅存本机偏好，不进入个人备份；Android排除声明联网必需或未安装音色，不据此代替真实离线验收。

MeloTTS与Kokoro随应用提供，解包/恢复按固定清单验证，不传输用户文字。Kokoro附带espeak-ng数据；模型、数据、引擎的许可和来源分别保留，新增文件的正式分发义务仍需在发行阶段审核。读取许可明确性和模型能力不等于已取得商店或最终发行批准。
