# 05 · 多语言、教学译文与界面文案

> HanMate 文档包 v3.0 · 2026-09-14 · 状态：开发基线提案，非已实现报告。
> 正式名称：HanMate / 汉语小伴；R01—R22 为需求基线，其余明确标注的规则为可调整默认设计。

## 1. 三层语言必须隔离

| 数据 | 是否随 UI 语言变化 | 存储位置 |
|---|---|---|
| 导航、按钮、错误、分类标签 | 是 | `.resx` 资源 |
| 汉字、词语、诗词、例句、拼音、中文释义 | 否 | 内容文档 |
| 日英词义与句段辅助译文 | 是；中文时不显示 | 内容文档 `translations` |
| 用户收藏夹名、录音名、个人标题 | 否 | 用户数据 |
| 系统默认收藏夹显示名 | 是 | 由固定 systemRole 和 UI 资源得出 |

语种为 `zh-Hans`、`ja`、`en`。语言切换不能改内容 ID、正文哈希、拼音来源、音频适用哈希。由语言决定的显示字段是投影，不是新的内容版本。

## 2. 语言解析与持久化

首次系统语言按 `zh-* / ja-* / 其他` 映射，之后使用明确设置。`UserSettings.uiLanguage` 是迁移主数据；CultureInfo 和启动 Preferences 仅为运行时状态/可重建缓存。

资源默认英文，中文与日文分别提供完整资源；不得依赖缺失资源的默认回退来通过三语言验收。UI 资源翻译缺失是发布缺陷；个人正文缺译文不是功能错误。

资源文件本地化是 MAUI 官方提供的能力，运行时通知、主导航即时刷新、平台语言声明仍由本应用实现。[S03](27_References.md)

## 3. 即时切换事务

1. 验证目标语言在允许集合。
2. 写入设置；失败不改变当前语言。
3. 通过 UI 线程切换资源服务并发出 `LanguageChanged`。
4. 刷新当前页、Shell 导航、弹层后续文案、分类、系统夹显示名。
5. 保留内容、滚动、搜索输入和未保存草稿；关闭并重开弹层不是丢弃草稿的理由。

绑定不能只在构造函数读取一次 `AppResources.X`。ViewModel 应订阅可释放的语言通知，或使用可更新资源索引器。具体技术选用需在 M0/M1 验证。

## 4. 辅助译文选择函数

```text
SelectTranslation(translations, uiLanguage):
    zh-Hans -> null（隐藏整个译文容器，包含其边距）
    ja      -> translations.ja 非空时返回，否则 null
    en      -> translations.en 非空时返回，否则 null
```

空字符串与全空白作为未提供处理。日语缺失不返回英语；正文仍可学习。编辑器可以显示“尚未填写日语译文”，普通学习页默认不重复制造“无译文”噪音。对正式内置内容，缺译文在内容审核环节拦截。

## 5. 中文朗读与 UI 语言无关

语音服务单独选普通话目标 locale，用户选择 ja/en 界面不能使汉字被日语或英语语音朗读。恢复另一设备的 voice ID 时必须重新解析，不把它当成跨平台稳定 ID。

UI 切换不重新生成音频，不改变已有录音。系统中文语音缺失使用可理解的 UI 提示；不将拼音字符串作为英语文本提交 TTS。

## 6. 文案键约定

键按 `Nav / Action / Label / Error / Dialog / Audio / Import / Settings / A11y` 分组，例如 `Nav.Pinyin`、`Error.PackageHashMismatch`。资源值不包含用于业务判断的编码。

含数值的文案用参数，如“将导入 {0} 个内容、{1} 个音频”；不拼接中文词序后再翻译。显示日期使用当前 UI 区域习惯；存储和 JSON 时间统一 UTC ISO 8601。排序、哈希和包数值序列化使用不受 UI 区域影响的确定规则。

初始文案表见 `examples/ui-copy.csv`，状态为草稿，需日英校对。不得虚构“母语审校已完成”。

## 7. 高风险文案规范

| 场景 | 建议中文表达 | 必须说明 |
|---|---|---|
| 删除收藏夹 | 删除此收藏夹？原内容和录音不会被删除。 | 删除对象 |
| 删除个人内容 | 将删除此内容，并移除其收藏关系。 | 引用与音频影响 |
| 替换恢复 | 将替换本机已保存的用户资料；继续前先创建安全备份。 | 破坏性与保护步骤 |
| 改读音 | 已修改显示拼音，请确认原音频读音是否一致。 | 拼音与音频不同步 |
| 系统语音缺失 | 当前没有可用的普通话语音，仍可阅读或导入录音。 | 不阻断阅读 |
| 包未加密 | 文件包含个人正文或声音，任何取得文件的人可能读取。 | 保密边界 |
| 系统分享 | 已打开系统分享，请在目标应用完成发送。 | 不宣称接收成功 |
| 取消保存 | 已取消，未保存到所选位置。 | 不伪报成功 |

## 8. 验收

测试三语言来回切换，包含主导航、四声弹层、错误提示、恢复预览、默认收藏夹和麦克风用途说明。测试正文在语言切换前后哈希完全相同；中文时布局无空译文行；个人缺译文不触发英语回退；将英文 UI 与普通话 TTS 组合试听。


## 9. 正式命名、语法和字典译文

产品英文名固定 HanMate，中文名汉语小伴；中文界面品牌展示“汉语小伴”，关于页保留 HanMate。日/英界面用 HanMate，不生成新品牌译名。应用 ID、包名、签名与商标占用需另行核查，不能据此自动更换已发布应用身份。

语法的中文说明、句型 literal 与 slot 中文名称、中文注意事项属于教学层，中文 UI 不能把它们一并隐藏。`grammar.patternTranslations` 和说明/例句的 translations 是辅助层，中文时隐藏。字典 definition 的中文释义同样保留。

资源包 names 可按 UI 选择 zh-Hans/ja/en，属于资源显示名，不改变资源 ID；缺名称可回退到其中文名称并显示来源，不与“教学译文禁止跨语言回退”混淆。外来作者自命名标题原样保留，禁止自动改写个人作品名。
