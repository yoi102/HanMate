# 04 · 视觉系统、注音组件与无障碍

> HanMate 文档包 v3.0 · 2026-09-14 · 状态：开发基线提案，非已实现报告。
> 正式名称：HanMate / 汉语小伴；R01—R22 为需求基线，其余明确标注的规则为可调整默认设计。

## 1. 设计目标

视觉以易读、安静、轻量为主。学习正文比装饰重要；不采用大量玻璃质感、复杂渐变和动态卡片来争夺注意力。此为本项目设计建议，不是要求模仿某个现有产品。

统一设计 token，避免每页独立决定边距、字号、按钮形状。颜色和尺寸为提案，发布前必须用真实页面和对比度工具验证；本包不声称已完成视觉验收。

## 2. 基础 token

| 类别 | 默认建议 | 使用原则 |
|---|---|---|
| 间距 | 4 / 8 / 12 / 16 / 24 / 32 | 页面内边距手机 16，宽屏 24；不以空格排版 |
| 圆角 | 8 / 12 / 16 | 小控件、卡片、弹层三个级别 |
| 正文字号 | UI 16；阅读汉字 24；拼音约 14 | 由系统缩放叠加；拼音不小到难以阅读 |
| 词语大字 | 汉字 36；拼音 20 | 长词可换行，不缩到难辨认 |
| 放大阅读 | 汉字 32，拼音 18 | 与原文相同数据，不生成另一份注音 |
| 辅助译文 | 14—16 | “小字”是视觉层级，不是固定微小字体 |
| 交互区域 | 48×48 逻辑单位为统一设计目标 | 图标可小，命中区域不能同样小 |
| 颜色语义 | Background / Surface / Text / Secondary / Accent / Error | 拼音红色为 TeachingHighlight，不能与错误状态混淆 |
| 字体 | 优先系统字体与明确合法的回退 | 不把机器上的字体文件直接打包分发 |

拼音高亮使用明确红色（候选 `#C62828`），同时辅以强调或下划线，保证色觉差异用户可识别。其他颜色不在需求中固定，交由主题资源统一定义。

## 3. 核心复用组件

| 组件 | 输入 | 输出事件 | 禁止职责 |
|---|---|---|---|
| RubyTextView | AnnotatedText、样式、选中 segment、可交互模式 | SegmentTapped、TokenEditRequested | 不直接访问数据库/TTS |
| PinyinTile | 教学项、播放状态 | PlayRequested、ExamplesRequested | 不自建全局音频实例 |
| ContentListItem | 摘要、译文选择、收藏状态 | Open、Play、Favorite | 不自己拼接查询 SQL |
| AudioButton | 会话状态、可播放原因 | Play/Stop | 不假定所有状态支持暂停 |
| FolderPicker | 当前成员集合、文件夹集合 | Confirm/Cancel | 关闭时不偷偷保存 |
| ImportSummary | 经过验证的导入计划 | Confirm/Cancel | 不直接信任未验证 manifest |
| StatusPanel | 错误码、已本地化信息、操作 | Retry/OpenSettings | 不把原始异常完整显示给用户 |

控件属性必须可通知、可测试；点击字、点段和整句播放模式显式区分，不依赖某页临时绑定顺序。

## 4. 注音控件的可访问性

普通阅读按句段提供语义朗读文本，避免屏幕阅读器同时把上方拼音与下方汉字读两遍。拼音学习或编辑模式可单独暴露 token 的“汉字、拼音、是否待复核”信息。纯自绘不能无语义节点；必要时使用平台可访问性适配层。

朗读按钮描述如“朗读例句：今天我去学校”，停止按钮有停止语义。收藏按钮暴露已收藏/未收藏以及打开选择器的行为。录音状态除颜色外显示“正在录音”和实际时长。

## 5. 布局和响应式

手机保持五项底部导航。Windows 首版可保持同结构，宽屏在内容区使用最大阅读宽度或主从布局，而不是把一行正文无限拉长。窗口缩窄后退回单栏，不遮挡保存和返回按钮。

内容列表只使用一个主滚动容器。阅读器虚拟化单位是可测量的布局行/块，不要求语义句段必须很短。超长无标点片段可以拆成多个视觉块，共用同一 segment ID；详见文档 09。

200% 字体缩放要验证：四声四行可滚动、上下拼音不截顶、对话框能关闭、底部输入不被键盘挡住、日英长按钮可换行。不能为了保持截图整齐而关闭系统字体缩放。

## 6. 键盘、焦点与触摸

Tab 顺序与视觉顺序一致；打开弹层聚焦标题或首个有效操作；关闭后回到触发控件；Esc 可取消非破坏性弹层。删除确认默认焦点不放在危险按钮上。

拼音项有可聚焦“示例”入口，不能要求键盘用户模拟长按。收藏夹排序提供上下移动。拖动滚动超过阈值时取消点击/长按，不在用户滑动列表时突然朗读。

## 7. 视觉验收素材

必须覆盖最窄目标手机宽度、横屏、Windows 小窗口和宽屏；中文/日文/英文各一组；正文混合 `ā á ǎ à ǖ ǘ ǚ ǜ`、汉字、日文、Emoji 和组合字符。截图记录系统缩放、应用字号、构建号。

截图只是显示证据，不替代声音、焦点、滚动和保存验证。此包提供设计规则，不包含声称已通过验收的 UI 截图。

## 8. 实现参考

MAUI 自定义布局提供测量与排列的扩展点；项目仍需实现注音单元测量、行布局、命中映射和无障碍。[S21](27_References.md) 不能把框架“支持自定义布局”当成已经存在完整 Ruby 控件。


## 9. 语法与资源管理视觉补充

语法句型用可换行的 slot/literal/operator 结构展示，真实例句继续用 Ruby 控件。slot 的样式区别不只靠颜色；教学中文不因语言设置替换。资源管理同时显示名称、版本、启用状态与来源，避免只靠开关颜色表达可用性。

危险操作明确写“撤下此内容”“卸载字典”“删除个人内容”，不把三者全部写成一个垃圾桶图标。多选分享显示已选数量，不常驻一排密集操作按钮。正式名称统一为 HanMate / 汉语小伴。
