# 30 · 语法学习与编辑详细设计

> HanMate · 汉语小伴 · 文档 v3.0 · 2026-09-14
> 正式产品名已确认；这是开发规格与数据契约，不是已实现或三平台测试报告。


## 1. 定位与范围

语法是 `ContentKind.Grammar`，与 word、text、poem 平级。学习页独立类型入口，支持场景/难度/学段筛选、预置资源、新建编辑、删除、收藏、音频和内容分享。首版不引入语法自动评分、出题、长文语法诊断或云服务。

## 2. 列表与详情 P12

列表显示中文标题，例如“‘正在’表示进行”、简短句型、难度、来源和收藏状态。日英辅助标题/结构译文随 UI 切换；中文 UI 不显示辅助译文，但**中文解释仍显示**。

| 详情区域 | 数据/显示 | 交互 |
|---|---|---|
| 页头 | 中文标题、分类、收藏、更多 | 更多含分享、音轨、编辑/复制编辑、删除 |
| 句型卡 | 结构化 `patternParts`；例如“主语 + 正在 + 动作” | 非整段播放目标；不把“+”或占位符交给 TTS |
| 用法说明 | 中文说明 TextUnit，上拼音下汉字 | 显式播放按钮读当前说明；小字译文按语言显示 |
| 正确例句 | 每句上拼音下汉字 | 点击整句朗读，不被课文逗号分段规则拆开 |
| 注意事项 | 可选中文注音 TextUnit + 日/英译文 | 默认不夹入例句播放队列 |
| 来源与审核 | 发布者、来源、个人/草稿状态 | 查看真实声明，不虚构官方认证 |

句型里所有教学中文固定；slot.text（主语、地点、动作等）是教学概念，不随 UI 改写。其日英解释统一放 `patternTranslations`，中文时隐藏这一行。窄屏允许句型单元换行，不把整个公式压成不可读小字。

## 3. 数据契约

`ContentDocument.schemaVersion=2`、`kind=grammar`。沿用稳定 ID、难度、场景、学段和三种修订版本。

```text
grammar
  patternParts[]               kind=literal|slot|operator, text
  patternTranslations          可选 ja/en
  explanationUnitIds[]         至少一个，role=grammarExplanation
  exampleUnitIds[]             至少一个，role=example
  noteUnitIds[]                可空，role=grammarNote
  topicCodes[]                 结构标签，不作为 UI 文案
textUnits[]                    所有真实中文说明/例句的字音主数据
```

结构卡只存声明式文本，禁止可执行表达式、JS 或 HTML；不将它当模板代码求值。标题不混入正文范围。数组中的 unitId 必须指向本条内容，按数组顺序展示；每个语法 unit 恰好属于一个列表，不得遗漏、重复、引用别条内容。

## 4. 保存不变量

保存为正式个人语法至少需要非空标题、一个结构单元、一段用法说明、一条例句。缺这些可保存草稿，不生成看似完整的假例句。正式预置语法默认至少两条审校例句；个人保存可只有一条。

`grammar` 字段只允许在 grammar 内容中出现。grammar 不含 headword/body，普通课文不能夹带 grammar 指令。各 TextUnit 都用既有 token/segment 覆盖规则校验，拼音不能只存一条总字符串。

## 5. 新建、导入与修改

新建→选语法→填写标题和句型→输入中文说明/例句→离线注音→人工校正→可选译文/录音→保存。TXT 导入选语法时，全文先进入说明草稿，用户再拆例句并补句型；不宣称可自动识别任意文档的正确语法结构。

语法资源只读；修改时“复制为我的语法”，给全部 content/unit/segment/token 新 ID，保留来源与权利说明，不能把别人的文本改名成自己的原创。只改某例句的拼音不覆盖其他例句。

## 6. 读音与音源

例句以 unit 为播放目标，点句读整句。中文说明可以用 unit 播放；不默认点句型结构朗读。录音界面明确显示“说明”“例句 1”“注意事项”，禁止把结构卡的编号当音频 targetId。

修改结构卡或标题但不改某例句文字/拼音，例句录音保持有效。修改例句有效读音，该 unit 和受影响片段的音轨 needsReview。仅切换 UI、锁定开关或译文不使音频失效。已有完整录音不自动拥有逐例句时间轴。

## 7. 分类与扩展

难度与学段互相独立；语法主题可以是 location、progressive、comparison 等 code，显示名称用 UI 资源。未分年级不默认为小学。可以按教材标签扩展，但没有具体教材授权时不宣称课程覆盖。

首版至少预留否定、疑问、比较、时间、位置等主题目录；只有确有审校内容的分类显示数量，不生成不存在的课程。

## 8. 收藏、删除、分享

收藏整个语法点，引用 contentId；不是仅收藏一个无上下文句型字符串。删除个人语法需要预览收藏/录音影响；撤下资源语法保留受引用快照。

分享语法默认带整条结构、说明、例句、人工拼音、可选译文及被选音轨。不得只导出例句文本却让 grammar.explanationUnitIds 悬空。接收方导入为个人语法，不得到源资源的安装/更新权限。

## 9. UI 状态与访问性

EmptyGrammar、DraftIncomplete、Ready、AudioMissing、NeedsReview、SourceRemoved 分开显示。缺译文不报整个页面错误；缺音频仍可学习。句型 slot 采用语义标签，例如“句型占位：主语”，不只用彩色区分；键盘可逐例句朗读。

## 10. 验收重点

四类型切换、语法筛选、中文说明不被误隐藏、例句带调对齐、整句播放、结构不误读、编辑锁定保存、错误引用拒绝、个人与资源删除区别、语法分享/备份往返。工程样例 `examples/grammar-content.json` 和 HM-T129—HM-T140 覆盖这些规则，样例仍是未终审草稿。
