# 25 · 风险清单与应对措施

> HanMate 文档包 v3.0 · 2026-09-14 · 状态：开发基线提案，非已实现报告。
> 正式名称：HanMate / 汉语小伴；R01—R22 为需求基线，其余明确标注的规则为可调整默认设计。

## 1. 风险分级

概率/影响为设计评估，不是统计结论。责任人先标“待分配”，不能假造团队已经配置。触发风险后更新 ISSUES 和阶段门，不只保留一张静态风险表。

| ID | 风险 | 概率/影响 | 应对与触发条件 |
|---|---|---|---|
| K01 | 多音字、人名/古文误音 | 高/高 | 词组词典+可解释候选+手工锁定；基准错误即登记，不宣称全正确 |
| K02 | Ruby 长文性能差 | 中/高 | M0 长文/缩放验证、可视区布局；禁止全部原生控件堆叠 |
| K03 | TTS 不服从人工拼音 | 高/高 | 注音与音源分离、录音优先、修改后复核 |
| K04 | 三平台录音编码不同 | 中/高 | M0 真实录音互播；锁定容器+编码组合，不只看后缀 |
| K05 | iOS 构建环境缺失 | 中/高 | 及早记录 Mac/Xcode/设备；独立逻辑继续，iOS 不虚报通过 |
| K06 | 编辑后 ID/范围错配 | 中/高 | 文本元素映射、稳定 IDs、歧义人工确认、属性测试 |
| K07 | 恢复过程丢资料 | 中/极高 | 安全备份、文件先安装、事务收据、故障注入 |
| K08 | 分享包含无关隐私 | 中/极高 | 明确选择闭包和白名单；分享包禁止 settings/collections |
| K09 | 教材/音频/字典许可不清 | 中/高 | 分素材来源审核；未许可不发行，不以仓库名作授权证明 |
| K10 | 系统语音实际联网 | 中/高 | 本地音源/严格本地策略；说明系统行为边界，实测 |
| K11 | ZIP 路径与资源攻击 | 中/高 | 白名单、流式限额、深度/引用验证，写库前拒绝 |
| K12 | AI 随意删减 P0 | 中/高 | R01—R22 追踪、AGENTS、阶段完成定义 |
| K13 | 文档与代码逐渐不一致 | 高/中 | 每次 PR 更新契约和 tests；生成派生表，不维护多真源 |
| K14 | 内置目录升级破坏用户绑定 | 中/高 | 目录修订与用户层分离，快照和音频复核 |
| K15 | 容量上限阻断完整备份 | 中/高 | 导出前预估；真实数据测上限，不静默漏录音 |
| K16 | 数据 schema 过早复杂化 | 中/中 | 单库+JSON 真源；不用云同步/微服务；每表有实际用途 |
| K17 | 字体裁剪/系统缩放缺字 | 中/中 | 四调及 ü、CJK、组合字符测试；字体许可独立审核 |
| K18 | 正式素材数量拖慢交付 | 中/中 | 软件/内容双轨、先开发样例，再按审核数量发布 |

## 2. 首轮必须解决的风险

K02/K04/K05 在 M0 验证，不等到页面全部完成才发现平台不支持。K06/K07 在进入 M4 前必须有自动化断言与失败样例。K09/K10/K11 为发行门槛，不可只写免责声明替代实现或审查。

## 3. 降级原则

允许的降级：无中文系统语音仍可阅读、无译文正常显示中文、未知字音标记待确认、无合法音频不播放、导入超限拒绝。禁止的降级：改用错误语言朗读、删掉用户正文、悄悄上传云端、自动覆盖人工拼音、把静音当示范。


## 4. v3 新增风险

| 风险 | 影响 | 控制与证据 |
|---|---|---|
| grammar 仅新增枚举未实现详情 | 看似支持，实际无句型/例句 | 独立模型/页面/编辑与用例 |
| 卸载字典误删注音库 | 用户导入无法注音 | 服务/存储隔离、最后字典卸载测试 |
| 卸载资源级联删除用户录音 | 无法挽回的资料损失 | 依赖预览、retained快照、GC租约 |
| 同版本不同载荷覆盖 | 数据供应链与身份冲突 | 指纹冲突拒绝、不信清单自称官方 |
| 撤下项升级后复活 | 用户管理状态丢失 | entryId稳定与跨版本override |
| 完整备份漏资源 | 换机不可用 | included/referenceOnly和明确警告 |
| 旧数据被新DDL重建 | 收藏/校正丢失 | 专门migration，不用新建脚本升级 |
