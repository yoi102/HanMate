# 03 · 页面与组件详细规格

> HanMate 文档包 v3.0 · 2026-09-14 · 状态：开发基线提案，非已实现报告。
> 正式名称：HanMate / 汉语小伴；R01—R22 为需求基线，其余明确标注的规则为可调整默认设计。

## 1. 共用页面规范

五入口名称不按不同页面随意变化；正文学习区域和页面操作栏视觉分层。列表使用真实数据源、稳定 item key 和分页/虚拟化，不嵌套两个争抢滚动的纵向容器。详情返回保留列表上下文。

每个按钮必须有实际行为、禁用原因与辅助语义。演示阶段没有能力的按钮明确标“未实现”且不可进入正式发行版本；不弹“成功”来代替真正操作。

## 2. P01 拼音页

按分组纵向排列可换行的拼音条目；按用户2026-09-19要求，顶部不放页面说明、覆盖统计或工具按钮。来源与教学目录导入移至设置。分组允许快速定位，但不拆成多个必须反复返回的页面。

2026-09-20用户修订使用向导：采用真实目标镂空高亮、其余界面遮暗、箭头与文字提示的四步引导，不使用弹窗内复制的示范按钮。按用户后续要求，黑色遮罩为60%透明度，即40%不透明度，目标和提示保持清晰。第一步单击拼音听读音，第二步长按该拼音进入例字例词页；第三步单击例字听读音，第四步长按例字打开字典释义。对应手势成功后推进，步骤贯穿两页，允许随时跳过。第一分组右侧的小“？”重看；本机使用v2完成标记，已看过旧两步向导的用户仍能看到新版。窗口变化时重新定位箭头与高亮，非目标区域拦截误触；支持三语言，Windows补充右键/F10。见 `tracking/evidence/PINYIN-SPOTLIGHT-20260920.md`，旧版证据保留为历史记录。

点击条目播放专用示范音频，声母使用bo、po、mo、fo等常见教学读音，不再取首个例字ba、pa、ma、fa冒充示范。长按500 ms进入例词页，拖动进入滚动后取消长按，长按完成不补发click。Windows提供右键、触屏按住及F10入口；不显示独立“例词”按钮。读屏说明保留在语义描述中。[S08](27_References.md)

### 四声例词视图

使用可返回的原生详情页承载例字与例词，不放说明、停止或来源工具栏。来源统一在设置查阅。示范录音缺失时明确提示，独立ong不得以dong代替；正式审核门禁不因此关闭。

标题是所选拼音项，按一至四声分组，只显示有例词的声调，每组可有多个带完整拼音的例字/例词和日/英译文（中文UI隐藏译文及空白）。直接点击例词朗读其完整录音，以行背景表示播放；无独立播放按钮。长按进入搜索结果复用的ReadingPage词条解释页：优先完全匹配文字与读音的已安装词条，未找到时显示随附原创草稿释义且只读，不自动写入字典。轻声保持词内实际读音，不单独冒充四声例字。

高亮来自教学项的例词映射：定位到 `contentId / unitId / tokenId` 与拼音文本元素范围，只标红目标拼音范围，并增加下划线或强调标记。当前只读课程字段为 `pinyinStart / pinyinLength`；不是外部资源包新协议。四声缺失不使用轻声顶替。离开视图停止其触发的例词播放，返回保留原列表上下文；焦点与读屏须按平台验收。

## 3. P02 学习页

第一层切换词语、课文、语法、诗词；第二层为筛选区域；右上角“新建/导入”，另提供“管理内容”菜单进入 P13。筛选维度为场景、难度、学段/年级、来源。可折叠筛选，不让所有标签占满首屏。当前生效条件有摘要和“清除”。

词语列表显示汉字、带调拼音、当前语言译文、收藏状态和独立朗读按钮。语法列表显示句型摘要并进入 P12；课文/诗词列表显示中文标题、作者、短摘要和必要标签；标题译文是辅助行，中文 UI 隐藏。点击空白正文区进入详情，音频按钮不冒泡到导航。

空列表区分“当前无此类内容”和“筛选后没有匹配”。前者可引导导入，后者优先清筛选。来源“我的”显示输入、TXT 导入与分享导入的个人资料；草稿单独有入口，不混作正式学习内容。

## 4. P06 词语详情

| 区域 | 内容 | 交互 |
|---|---|---|
| 顶部操作 | 返回、收藏、更多 | 更多含分享；个人内容另有编辑/音频 |
| 词语头部 | 逐字注音、大字词语、读音/义项说明 | 点击头部或播放按钮，播放当前词条 |
| 释义 | 中文教学释义及当前 ja/en 辅助译文 | 中文 UI 只隐藏辅助译文，不删中文释义 |
| 例句 | 每句上拼音下汉字，下方句译文 | 点击整条例句播放完整例句 |
| 来源 | 提供方、审核/个人状态 | 查看来源详情，不伪造认证 |

相同汉字的其他读音或义项仅在库中确有数据时提供切换。词条头部与每条例句都是独立 `TextUnit`，各自拥有音频目标。词语收藏收藏当前词条 ID；播放例句不自动收藏整篇句子。

默认内置词条至少两条审核例句，个人词条允许零例句；缺例句不生成占位“例句1”。正文或读音需复核时以轻量提示呈现，不让草稿审核标记被隐藏。

## 5. P07 阅读器

标题、作者与来源在正文上方；工具栏含拼音显示、字号、全文朗读、收藏、更多。正文按原段落和诗行展示；译文在相应片段下方，不按一个汉字一条译文排列。

点段行为按文档 09 执行。放大弹层只有一个实例，内容过长可以滚动；顶部显示段落位置，底部为上一段、播放/停止、下一段、关闭。上下段按钮到边界时禁用，不循环跳转。

全文播放有“按段朗读”与“整篇录音”两种真实模式，有整篇音源时可选择；只有段录音/TTS 时显示按段模式。没有可靠时间轴的整篇录音只显示整体播放状态，不假装逐段高亮。全文播放切换模式先停止旧会话。

## 6. P03 搜索页

结果区域占据上方，底部输入框位于主导航之上，安全区及软键盘弹出时保持可见。输入框包含清除按钮，提示“输入汉字或拼音”；空态提供 `你好 / nihao / nǐ hǎo` 示例。

有效输入防抖 250 ms；Windows Enter 立即提交。首次显示最多 50 条，继续分页；结果排序必须可重复。首版支持词条，不将课文正文检索冒充已实现。可以保留内容类型扩展位置，但未实现时不显示可选空筛选。

搜索输入为中文输入法组合态时不主动回写输入框，不打断候选选择；识别已提交文本。已发出的旧请求可取消，无法取消时通过 queryId 丢弃旧结果。

## 7. P04 收藏页与 P10 收藏夹详情

收藏主页面显示收藏夹名称、条目数与最后变动信息，可新建、重命名、修改说明、排序、删除。默认夹有明确系统角色，不因 UI 切换产生多个语言名称夹。用户排序可拖动，也要有“上移/下移”无障碍替代。

详情按内容类型显示一致的条目卡片，允许移除收藏或修改所属夹。删除收藏夹确认文案明确“不会删除原词语、课文或录音”。删除个人内容从内容菜单操作，并另行显示影响的收藏和音频引用数量。

## 8. P05 设置页

| 组 | 控件 | 保存和反馈 |
|---|---|---|
| 显示语言 | 简中/日本語/English 单选 | 即时持久化并刷新，不重启清导航 |
| 阅读 | 字号 18—40 默认 24；显示拼音 | 预览当前学习片段；数字为默认逻辑尺寸 |
| 音频 | 可用普通话语音、试听、本地音源说明 | 语音不存在时正常回退，不读成 UI 语言 |
| 内容与字典 | 学习资源/字典管理、保留资料、已撤下条目 | 不把禁用、卸载和删除个人资料混为一项 |
| 数据迁移 | 导出完整备份、导入备份、导入内容包 | 进入预览和确认流程 |
| 存储 | 正式资料、录音、草稿、缓存分项容量 | 清缓存只删可重建缓存 |
| 关于 | 版本、内容版本、隐私、来源、许可 | 实际版本与真实文件清单 |

主题和变速不是首版必需；不放无效开关。选项写入失败时恢复旧值并解释，不让 UI 已改变而数据库仍旧。

## 9. P08 新建与文本编辑器

顶部显示类型、标题、保存；正文编辑区始终可恢复原文。注音编辑在预览模式中进行，用户点击 token 修改拼音；不要在一个自由文本框中同时编辑汉字和整行拼音位置。

提供“生成/补全拼音”“只处理未锁定项”“预览全部重生成”的不同语义。新建正文为空、类型不合法、标题空白不可保存正式内容。超限显示计数与上限，不截断。个人译文、标签、来源说明放在可折叠辅助区。

切换正文与注音预览之前完成输入法提交和草稿同步。正文变更后展示“哪些读音校正保留、哪些需要复核、哪些音频受影响”的结果。人工分段只影响边界，不插入或删除正文标点。

## 10. P09 音频管理

按当前目标列出音轨：名称、来源、时长、是否默认、是否待复核。操作为试听、录音、导入、设为默认、重命名、解除绑定/删除。明确“整篇”与“当前片段”，避免用户不知道声音配到哪里。

录音界面显示目标文字、录音状态、时长、停止按钮；停止后有试听、重录、保存与丢弃。录音默认名称由时间与目标摘要形成，可修改。权限拒绝仍保留内容编辑状态。

## 11. P11 迁移预览

显示包类型、导出时间、内容/收藏夹/音频数、大小、缺失音源、冲突数和权限范围。分享包不能选“替换所有用户数据”。备份合并默认不应用外来设置；替换模式说明删除当前用户数据并二次确认。

完成汇总必须区分新增、复用、派生、跳过、未恢复和警告，不只显示一个“成功”。存在未恢复项时可查看具体列表，错误详情不泄露源设备绝对路径。
