# 13 · 收藏夹、设置与本地数据管理

> HanMate 文档包 v3.0 · 2026-09-14 · 状态：开发基线提案，非已实现报告。
> 正式名称：HanMate / 汉语小伴；R01—R22 为需求基线，其余明确标注的规则为可调整默认设计。

## 1. 收藏对象与唯一性

word/text/grammar/poem 都可收藏；每个 word ID 已对应明确音义项。收藏存稳定内容引用，不复制一份日后无法同步的正文。快照用于备份、资源卸载和更新时保护仍被引用的旧内容；普通收藏不创建副本。

一个内容可出现在多个夹，同一 `(folderId,contentId)` 只能出现一次。收藏选择器一次提交最终所属夹集合：新加入的插入，取消的删除，未变的不动；事务失败整体保持旧集合。

## 2. 收藏夹规则

名称 trim 后 1—40 文本元素；说明默认 ≤300 元素。普通夹名称使用统一 nameKey，大小写和 Unicode 规范化后的同名不允许。系统默认夹以 `systemRole=default` 标识，唯一、不可删除，显示名按 UI 语言生成；不能把中文显示名当身份。

普通夹可新建、重命名、改说明、排序、删除。排序持久化为整数并定期事务内重排，不依赖创建时间或操作系统文件顺序。支持拖动和上移/下移两种路径。

## 3. 删除语义

删除收藏夹只删除夹与关系。移除收藏只删除关系。删除个人内容才影响正文及相关收藏，并在确认前列出受影响数量。音频物理文件按全库引用和租约回收，不能直接递归删除以正文标题命名的文件夹。

内置和外部资源条目支持首版“撤下/恢复”：持久化 resource_entry_override，从普通列表和查询排除，保留收藏和用户录音引用；不直接改写源包。整包卸载按文档 31 执行，不能用取消收藏或临时筛选代替内容管理。

## 4. 缺失内容处理

先用稳定 ID 解析本地内容；目录版本变化时按快照/映射恢复可读数据。无法恢复显示“内容暂不可用”和来源，不出现空白详情，不悄悄删收藏。

有用户音轨绑定的内置内容即使未收藏，也属于备份依赖集合。备份不能只遍历收藏夹而漏掉“没收藏但录了跟读音频”的目标。

## 5. 可迁移设置

| 设置键 | 默认值 | 恢复规则 |
|---|---|---|
| uiLanguage | 首次系统映射 | 合并默认保留本机；替换应用备份值 |
| reading.showPinyin | true | 即时刷新 |
| reading.fontSize | 24，允许 18—40 | 非法值拒绝/兼容迁移，不静默溢出 |
| audio.policy | localWithSystemFallback | 可改 localOnly，不启用云服务 |
| audio.preferredLocale | 普通话偏好，如 zh-CN | 目标设备重新查找可用声音 |
| favorites.lastFolderId | 默认夹 | 恢复后按 ID 映射；不存在回默认夹 |

设备 voiceId、临时路径、麦克风权限结果、缓存大小、窗口句柄不能作为可迁移设置。UI 的字号是应用偏好，仍需叠加系统字体缩放。

## 6. 设置保存一致性

数据库为主，Preferences 若使用只是启动缓存。修改成功后发通知更新 UI，失败回滚控件值并说明。恢复后重新从数据库加载，不让旧 Preferences 覆盖新备份设置。

切换语言不触发正文版本、音频哈希或索引重建。lastFolderId 的失效不能让收藏弹层无法打开；只回默认夹并记录非敏感诊断。

## 7. 存储页

分别统计：正式个人内容、用户音频、内置目录/音频、草稿、可清缓存、临时导出包。异步计算可取消，不通过 UI 线程遍历大量文件。

“清理缓存”仅清可重建的布局/索引临时副本和过期分享临时文件；不清正式用户录音、草稿或安全备份。删除草稿和删除本地安全备份用单独明确入口。

首版不提供一键“清空全部数据”作为解决问题的默认方法。若以后增加重置必须二次确认、先备份、说明卸载与系统备份边界。

## 8. 备份偏好边界

完整备份默认带全部已保存用户录音，以及许可允许携带的资源正文和标准音频，规则以文档 15 为准。不能一律排除安装包自带音频。来源受限或容量超限时阻止完整导出；用户明确接受部分资源备份后才使用 referenceOnly/catalogRef，并列明缺失范围。

内容分享不带设置。合并完整备份默认不改本机语言/字号；新安装可在预览页推荐勾选“应用设置”，但仍显示选择。替换恢复使用备份可迁移设置并重映射文件夹和声音偏好。

## 9. 测试

重复添加、同名不同 Unicode 组合名、三语言默认夹、重启排序、删除夹不删音频、多夹移除、删除个人内容关联清理、失效 lastFolderId、设置写入失败与合并/替换差异都要覆盖。数据库去重与 UI 防连点同时存在，不能只靠前端按钮禁用实现唯一性。


## 10. 四类收藏与资源依赖

收藏支持 word/text/grammar/poem，点击按 kind 导航，不把 grammar 打开为普通课文。字典词条同样可以收藏。资源撤下/卸载默认保留受引用内容快照，收藏显示来源已移除，用户录音继续关联。

设置增加“内容与字典”，与学习/搜索页使用同一个管理模块。资源 enabled/priority、entryOverride 不塞进 UserSettings 任意扩展字段，而按 resources.json 单独备份；恢复必须同时刷新搜索集合。

取消收藏不意味着立刻删除 retained 内容：先检查录音/草稿/其他夹/明确保留，只有无引用且经过规定清理确认才回收。原“删除收藏夹不伤正文/录音”的规则继续适用。

## 11. 当前基础交付 · 2026-09-17

## 12. 字典解释页收藏（ADR-107，2026-09-20）

词头文字是可键盘/读屏操作的播放入口，不再显示独立播放按钮。词头旁为48×48触控范围的星形图标：未收藏空心、已收藏实心；有本地化辅助标签，保存期间防止重复点击。

普通个人/资源词条沿用favorite_item：加入默认夹，取消时移除全部夹关系，不删除正文或音频。独立默认字典及随附只读拼音词条保存在user_settings.body_json.dictionaryBookmarks，按(provider,entryId)唯一，title仅供列表显示；不复制解释、自动注音或音频。收藏页提供“字典收藏”入口，按50条分页，可重新打开或移除。来源版本不再包含该ID时保留引用并提示，不悄悄删除。

该JSON字段缺失视为空，使用原有row_revision乐观锁合并，保留其他设置；SQLite user_version维持2。支持chinese-xinhua和bundled-pinyin，最多10000条，拒绝空UUID/空白标题/重复引用。备份与兼容按14/15/34执行。自动验证见tracking/evidence/DICTIONARY-FAVORITES-20260920.md；设备/UI验收仍未执行。
