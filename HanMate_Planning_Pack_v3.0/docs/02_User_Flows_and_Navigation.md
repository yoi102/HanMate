# 02 · 用户流程与导航规则

> HanMate 文档包 v3.0 · 2026-09-14 · 状态：开发基线提案，非已实现报告。
> 正式名称：HanMate / 汉语小伴；R01—R22 为需求基线，其余明确标注的规则为可调整默认设计。

## 1. 页面和路由登记

路由字符串为项目约定，不代表 MAUI 已经提供这些页面。路由参数只传稳定 ID 和简单显示模式；内容对象从仓储重新获取。

| 页面 ID | 路由建议 | 入口 | 返回目标 |
|---|---|---|---|
| P01 | `//pinyin` | 主导航 | 主入口，无重复堆栈 |
| P02 | `//learn` | 主导航 | 保留类型、筛选与滚动 |
| P03 | `//search` | 主导航 | 保留查询和滚动 |
| P04 | `//favorites` | 主导航 | 保留所选收藏夹 |
| P05 | `//settings` | 主导航 | 保留当前设置位置 |
| P06 | `word?id={id}` | 学习、搜索、收藏 | 回到真实来源页面 |
| P07 | `reader?id={id}` | 学习、收藏 | 回到真实来源页面 |
| P08 | `editor?id={id?}` | 新建、导入、个人内容菜单 | 保存后详情；取消回原来源 |
| P09 | `audio?targetId={id}` | 详情或编辑器音频管理 | 原详情/编辑草稿 |
| P10 | `folder?id={id}` | 收藏夹列表 | 收藏主入口 |
| P11 | `transfer?kind={backup|content|resource}` | 分享、设置、资源管理 | 操作完成后原页面 |
| P12 | `grammar?id={id}` | 学习、收藏、分享导入 | 回到真实来源页面 |
| P13 | `resources?kind=learning` | 学习页、设置 | 同一管理页复用 |
| P14 | `resources?kind=dictionary` | 搜索页、设置 | 保留搜索上下文 |
| P15 | `share?selectionId={id}` | 内容详情、列表多选、音频管理 | 分享取消回原选择 |

四声、放大阅读、收藏选择、拼音修改是弹层，不产生新的主导航。弹层自身必须有标题、关闭路径、焦点恢复和取消语义。

## 2. 首次使用

首次启动依次完成数据库迁移、内置内容校验/安装和语言解析。失败时显示可恢复错误页，不让用户进入缺表页面。首次语言规则：系统 `zh-*` → `zh-Hans`，`ja-*` → `ja`，其他 → `en`；设置页可立即更改。

默认直接进入拼音页，可用一句提示介绍点击和长按，但不强制观看多页引导。没有网络、没有麦克风权限、没有中文 TTS 都不阻止进入阅读和搜索。默认收藏夹创建由数据库唯一系统角色保证，不由每次进入页面创建。

## 3. 学习和收藏流程

```text
学习列表 → 选择类型与分类 → 点击内容正文 → 详情
                                      ├→ 点击音频按钮：仅播放
                                      └→ 点击收藏：选择一个或多个收藏夹 → 保存
```

收藏弹层的选择是一次批量提交。关闭/取消不提交临时勾选。未收藏时默认选最近使用夹；已收藏时勾选真实现有集合。移除全部需要用户点击“保存”确认，不用单次星形按钮点击悄悄移除所有夹。

收藏夹名称失效、内容已删除、保存时数据库忙等均保留当前选择，显示原因，可重试。若内容在页面打开后被删除，提交返回 `CONTENT_NOT_FOUND`，不生成悬空引用。

## 4. 阅读流程

点击正文片段 → 标记选中 → 打开/更新同一个放大弹层 → 取消旧播放 → 朗读当前片段 → 到片段末尾停止。再次点击相同正在播放的片段停止；点击其他片段替换当前播放。

弹层上一段/下一段只切换内容和选中状态，默认不自动发声。全文朗读是独立按钮；用户点段、关闭关联弹层、退出页面、进入后台均按音频规则取消相应会话。不能因为旧音频晚到的“完成事件”自动跳到下一段。

只有整篇录音时，全文入口可播放整篇；点段入口必须查找该段自己的音源或 TTS。界面明确显示“整篇录音，暂无逐段定位”，不高亮推算出来的段落。

## 5. 个人资料流程

```text
新建/导入 → 正文预览 → 类型/标题 → 自动注音
→ 校正读音/边界 → 可选译文 → 可选录音或导入语音 → 保存
```

不强制每一步都完成：正文有效即可保存草稿；“保存为学习内容”允许有待复核读音，但详情显示待复核状态。录音和译文可后补。录音工作区引用草稿的稳定文本单元 ID，最终保存时一并提交，不提前把半成品加入正式收藏。

离开有修改的编辑器时显示“保存草稿 / 丢弃 / 继续编辑”。应用切后台不弹确认框，而是尽力持久化草稿；重新打开提供恢复入口。草稿不是正式内容，完整备份前列出未保存草稿并提示先保存，不能暗示它们已经被迁移。

## 6. 分享和迁移流程

分享：选择内容及音轨 → 权限/来源规则检查 → 预览文件内容 → 生成临时包 → 系统分享或另存。关闭系统分享面板，只能说明“已打开系统分享”，不能在无法确定接收结果时说“对方已收到”。

备份：读取一致性快照 → 导出校验 → 系统保存 → 根据保存 API 的真实结果给出状态。取消保存不是成功。

恢复：选包 → 校验 → 冲突预览 → 合并/替换选择 → 本机安全备份（替换必需） → 暂存 → 提交 → 汇总。提交前可取消；短暂提交区不可半途取消，界面说明“正在完成保存”，完成后展示真实结果。

## 7. 页面状态统一

| 状态 | 画面 | 可做的操作 |
|---|---|---|
| Loading | 局部加载状态，避免全屏闪白 | 返回；可取消的任务可取消 |
| Ready | 内容与可用操作 | 正常操作 |
| Empty | 说明原因和一个相关入口 | 清筛选/新增内容等 |
| Error | 稳定错误说明与错误码 | 重试、返回、保留输入 |
| Dirty | 未保存提示 | 保存/丢弃/继续编辑 |
| BusyCommit | 提交状态，无重复按钮 | 不启动第二次写入 |
| MissingAsset | 正文正常，音源缺失说明 | 选音源、录音、导入 |

页面状态与音频状态分开，不用 `IsBusy` 一个布尔值控制整个应用。一个页面加载失败不应清空其他主导航的已保存状态。

## 8. Windows 与移动端统一语义

Windows 支持 Tab 遍历、Enter 激活、Esc 关闭弹层、右键替代长按、Ctrl+F 进入搜索。Ctrl+S 只在编辑器保存，不覆盖系统保存窗口快捷键。移动端返回键/系统返回手势调用同一个未保存保护；软键盘遮挡测试必须覆盖搜索底部输入框和编辑器。

快速双击内容最多打开一个详情实例；操作使用命令执行锁或导航去重。文件导入菜单一次只打开一个系统选择器，不因连点叠加授权窗口。


## 9. 新增流程的路由约束

四类型统一 `OpenContent(contentId)`：word→P06，text/poem→P07，grammar→P12。收藏或包导入不假定全部都是词语。无效/未知 kind 返回兼容错误，不打开空白阅读器。

资源安装：P13/P14→本地文件→P11 类型分派/校验→影响预览→确认→安装→回到管理页。单条撤下、卸载字典和个人删除都有自己的确认文案，不能共享一个无说明的“删除成功”。

分享选择以临时 selectionId 引用内存/私有暂存中的 ID 清单，不把整篇文章或音频字节放进 URI。用户取消选择不清空收藏。录音仍进行时先结束/保存，不从半成品生成分享包。
