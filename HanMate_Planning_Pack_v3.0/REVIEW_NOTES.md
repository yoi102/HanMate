# v3.0 整体复审与修订

> 2026-09-14。范围：规划文档、任务/验收清单、文档工具；未修改 MAUI 应用。

整体方向适合作为完整首版规划：MAUI 三平台、五入口、四类学习、离线注音与人工校正、录音和离线迁移可以形成完整闭环。Core 与平台能力分离、内容 JSON 真源和 SQLite 投影、不可变音频及恢复协议也有明确用途。
