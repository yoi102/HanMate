# 用户确认需求 · HanMate / 汉语小伴

> 2026-09-14。本页用于保留最新业务基线；实现细化见 docs。名称已正式确定。

## 平台与语言

.NET MAUI；iOS、Android、Windows。显示语言为简体中文、日语、英语。教学中文与拼音不随显示语言切换；小字辅助译文随设置；中文显示语言下不显示辅助译文。

## 五个主入口

**拼音。** 所有声母、韵母等同页向下滚动；点击发出对应声音；长按弹窗纵向展示四声四个真实例词，点击读完整例词，对应拼音部分红色突出，例词拼音有声调。

**学习。** 包含词语、课文、语法、诗词；多场景、多难度，也可按小学/初中/高中分类；四类均预先收录。可以添加和删除，为将来下载资料预留。词语详情顶部大字、带调拼音，点击发音；下面例句逐字注音，点击读整句；可收藏。课文上拼音下汉字，点击标点划分的小段会放大并朗读至片段结束。

**搜索。** 字典功能，底部输入框；输入汉字或拼音列出收录词语；字典可添加/删除，为将来下载预留。

**收藏。** 用户可以添加、删除、编辑收藏夹；点击收藏词条打开词语详情；新增四类资料按各自详情打开。

**设置。** 显示、阅读、音频、资源及数据管理；用户可将设置和收藏导出到一个文件进行离线迁移。

## 用户内容、录音与分享

自主输入/导入文本并自动产生拼音，用户可修改拼音。支持录制与导入语音，自己制作资料并分享。分享对象包括单词、课文、本人录音等；规划统一覆盖语法和诗词，可选单条或多条内容、可选音轨。

为保证迁移后资料可用，完整备份包含依赖的个人正文、人工校正和用户录音；资源管理状态/可备份字典同样纳入。未保存草稿、权限、设备专用路径和临时缓存的边界在备份文档中说明。

## 细化规则的性质

在线商店不是本轮要求立即实施的系统。资源协议、本地安装、删除引用保护、冲突处理和默认容量由规划补全；原要求不能由开发AI自行删减。
