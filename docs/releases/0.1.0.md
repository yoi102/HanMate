# HanMate 0.1.0 · Preview release preparation

简体中文 · English · 日本語

## 简体中文

0.1.0 是面向 Windows / Android 的开发预览版本，当前准备发布材料，尚未公开发布 Release。应用版本为 `0.1.0`，平台构建号为 `2`；保留现有应用标识，以便继续验证原安装的数据与升级路径。

### 本版内容

- 新的“中”字对话气泡图标，以及一致的启动画面。
- 中文、英文、日文 README，包含环境配置、构建和使用说明。
- 分类词语、数量词与例句、语法、课文、诗词；拼音与已有辅助译文。
- 词语点读与长按释义，课文和诗词标题、作者及正文片段点读。
- 收藏打开与学习模块一致的详情页，未变化的列表返回时保位。
- Melo / Kokoro 本地朗读、短词处理改进和特殊符号分隔预处理。

### 候选产物与安装

| 文件 | 用途 |
| --- | --- |
| `HanMate-0.1.0-windows-x64-preview.zip` | Windows x64 非打包应用，附带 .NET 与 Windows App SDK 运行文件；完整解压到独立目录后运行 `HanMate.App.exe`，不要只复制 EXE。 |
| `HanMate-0.1.0-android-arm64-dev-signed.apk` | Android ARM64 手机预览包，Release 配置、开发密钥签名；并非正式发行签名，不适用于 x86 模拟器。 |
| `SHA256SUMS.txt` | 文件完整性校验清单。 |
| `manifest.json` | 构建提交、版本、文件大小、哈希和验证边界。 |
| `release-preflight.json` | 现有发布检查器的实际结果，未完成项会保留为 BLOCKED。 |

内置语音模型使安装包较大。安装前使用应用内备份；Android 仅在应用标识和签名证书一致时支持覆盖升级。如果提示签名冲突，不要直接卸载原应用，以免丢失本地内容。Windows 覆盖升级前先退出应用。新装、升级、图标显示、音频与无障碍仍需要实际设备验证。

### 发布前尚需完成

- 正式发布标识、签名归属及新装/升级保数据验证；当前仍使用开发身份，Windows 包尚未签名。
- 教学内容与发音终审、字典及录音的再分发权利确认。
- 适用平台的完整设备回归、访问性与已知问题闭环。
- 项目整体许可证选择、最终隐私资料和正式发布决定。

构建与哈希检查通过不自动解除这些条件。现阶段不创建正式版本标签，也不公开上传候选二进制。完整状态见 [剩余工作](../../HanMate_Planning_Pack_v3.0/tracking/REMAINING_WORK.md) 和 [发布条件](../../HanMate_Planning_Pack_v3.0/tracking/deferred-release-gates.json)。

## English

0.1.0 is a Windows / Android development preview in preparation, not a published GitHub Release. The app version is `0.1.0` and its platform build number is `2`. Existing application identifiers are retained for upgrade and data-retention validation.

Highlights: a new Chinese-character speech-bubble icon and matching splash screen; Chinese, English and Japanese READMEs; vocabulary categories and examples; grammar, passages and poetry with pinyin and available translations; tap-to-read playback; consistent favorite detail pages; local Melo / Kokoro speech and symbol preprocessing.

The Windows x64 ZIP contains an unpackaged app with .NET and Windows App SDK runtime files. Extract the whole archive and run `HanMate.App.exe`. The Android APK targets **ARM64 devices**, uses Release configuration with a **development signing key**, and is not for x86 emulators. `SHA256SUMS.txt` and `manifest.json` record artifact hashes and the source commit; `release-preflight.json` retains unresolved release checks.

Back up in the app before installation. Android updates require matching identifiers and signing certificates. Do not uninstall an existing app to bypass a signature conflict, as this may delete local data. Exit the Windows app before replacing its files. Installation, upgrades, device icon rendering, audio and accessibility still need device validation.

Outstanding work includes production identity/signing, content and pronunciation review, dictionary and recording redistribution rights, device regression, overall project licensing and final privacy material. Build success is not release approval. No release tag or public binary upload is performed during this preparation.

## Reproduce the candidate / 重新准备 / 再作成

先提交源码，确保工作区干净并已拉取 Git LFS 资源。在具备 PowerShell 7.2+、MAUI、Windows SDK、Android SDK、JDK 和 Python 的 Windows 开发机上，从仓库根目录运行：

```powershell
./tools/prepare_release.ps1 -OutputDirectory ./artifacts/release-0.1.0-candidate -Python python3.14
```

The script requires a clean Git checkout and a new output directory. It performs locked restore, Windows publication, Android Release build, APK metadata/signature inspection, release preflight and checksum generation. It does not install the app, create signing keys, modify application IDs, create tags or publish anything. Automated tests and device checks are separate; their actual outcomes must be attached before a release decision.
