# HanMate 0.1.0 · Preview

简体中文 · English · 日本語

## 简体中文

0.1.0 是面向 Windows / Android 的开发预览版本，已于 2026-09-21 发布到 [GitHub Releases](https://github.com/yoi102/HanMate/releases/tag/v0.1.0)。应用版本为 `0.1.0`，平台构建号为 `2`。公开包对应提交 `98ba5818ee2ca77017a42280538cb2147f70d0aa`；后续商店配置不改变该标签。免费，无内购；Microsoft Store 与 Google Play 尚未上架。

### 本版内容

- 新的“中”字对话气泡图标，以及一致的启动画面。
- 中文、英文、日文 README，包含环境配置、构建和使用说明。
- 分类词语、数量词与例句、语法、课文、诗词；拼音与已有辅助译文。
- 词语点读与长按释义，课文和诗词标题、作者及正文片段点读。
- 收藏打开与学习模块一致的详情页，未变化的列表返回时保位。
- Melo / Kokoro 本地朗读、短词处理改进和特殊符号分隔预处理。

### 产物与安装

| 文件 | 用途 |
| --- | --- |
| `HanMate-0.1.0-windows-x64-preview.zip` | Windows x64 非打包应用，附带 .NET 与 Windows App SDK 运行文件；完整解压到独立目录后运行 `HanMate.App.exe`，不要只复制 EXE。 |
| `HanMate-0.1.0-android-arm64-dev-signed.apk` | Android ARM64 手机预览包，Release 配置、开发密钥签名；并非正式发行签名，不适用于 x86 模拟器。 |
| `SHA256SUMS.txt` | 文件完整性校验清单。 |
| `manifest.json` | 构建提交、版本、文件大小、哈希和验证边界。 |
| `release-preflight.json` | 现有发布检查器的实际结果，未完成项会保留为 BLOCKED。 |

内置语音模型使安装包较大。安装前使用应用内备份；Android 仅在应用标识和签名证书一致时支持覆盖升级。如果提示签名冲突，不要直接卸载原应用，以免丢失本地内容。Windows 覆盖升级前先退出应用。新装、升级、图标显示、音频与无障碍仍需要实际设备验证。

GitHub 附件为 Windows ZIP、Android APK 和 SHA256SUMS.txt；manifest.json 与 release-preflight.json 是本地构建证据，不是已上传附件。

## Reproduce the candidate / 重新准备 / 再作成

先提交源码，确保工作区干净并已拉取 Git LFS 资源。在具备 PowerShell 7.2+、MAUI、Windows SDK、Android SDK、JDK 和 Python 的 Windows 开发机上，从仓库根目录运行：

```powershell
./tools/prepare_release.ps1 -OutputDirectory ./artifacts/release-0.1.0-candidate -Python python3.14
```

The script requires a clean Git checkout and a new output directory. It performs locked restore, Windows publication, Android Release build, APK metadata/signature inspection, release preflight and checksum generation. It does not install the app, create signing keys, modify application IDs, create tags or publish anything. Automated tests and device checks are separate; their actual outcomes must be attached before a release decision.
