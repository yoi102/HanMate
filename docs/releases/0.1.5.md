# HanMate 0.1.5 · Preview

简体中文 · English · 日本語

## 简体中文

0.1.5 是 Windows x64 / Android ARM64 开发预览版，应用版本 `0.1.5`、平台构建号 `7`。免费，无内购；Microsoft Store 与 Google Play 尚未提供此版本。

### 本版内容

- 设置中新增系统、亮色、暗色主题选项，并突出显示当前选择。
- 修正 Windows 亮色主题下拼音页面的按钮对比度；拼音按钮文字、底色和边框会随明暗主题切换。
- 手机端将搜索模式切换放到标题栏并居中；搜索、手写例词和阅读页面对损坏数据及页面生命周期做了防护。
- Windows 拼音和例词操作支持鼠标单击与长按，鼠标右键用于返回。

### 下载与安装

Windows：下载 `HanMate-0.1.5-windows-x64-preview.zip`，关闭旧版后完整解压到原程序目录，再运行 `HanMate.App.exe`。Android：下载 `HanMate-0.1.5-android-arm64-dev-signed.apk`，仅适用于 ARM64 设备，使用开发签名；覆盖安装要求与旧版签名一致。升级前先使用应用内备份；若签名冲突，不要卸载旧版来绕过。使用 `SHA256SUMS.txt` 核对下载文件。

### 验证范围与已知限制

本版仍是开发预览，不代表商店批准或完整产品验收。Android APK 使用开发签名；正式签名、完整设备回归和商店发布条件尚未完成。教学内容、发音、译文的终审以及默认词库和音频的分发权利仍待核实；详情见[第三方许可核查](../THIRD_PARTY_LICENSES.md)及[后置发布门禁](../../HanMate_Planning_Pack_v3.0/tracking/deferred-release-gates.json)。设备未实际验证的项目不会标记为通过。构建、包签名、预检和文件哈希以本次发布资产中的 `manifest.json`、`release-preflight.json` 与 `SHA256SUMS.txt` 为准。

## English

HanMate 0.1.5 is a Windows x64 / Android ARM64 development preview. App version `0.1.5`, platform build number `7`. Free, with no in-app purchases; this version is not available through Microsoft Store or Google Play.

### What's new

- Settings now offers System, Light, and Dark themes and highlights the selected option.
- Fixed button contrast on the Windows pinyin page in Light mode. Pinyin button text, background, and border follow the selected theme.
- On phones, the search mode switch is centered in the title bar. Search, handwriting examples, and reading pages now handle damaged data and page lifecycle changes more safely.
- Windows pinyin and example actions support mouse clicks and holds; the right mouse button navigates back.

### Download and install

For Windows, download `HanMate-0.1.5-windows-x64-preview.zip`, close the old app, extract the complete archive over its program folder, and run `HanMate.App.exe`. The Android download, `HanMate-0.1.5-android-arm64-dev-signed.apk`, targets ARM64 devices and uses a development signing key; in-place upgrades require the same signing key as the installed copy. Back up in the app before upgrading. Do not uninstall an existing Android copy to work around a signature mismatch. Verify downloads with `SHA256SUMS.txt`.

### Validation and known limitations

This remains a development preview; it does not indicate Store approval or complete product acceptance. The Android APK uses a development certificate. Production signing, full device regression, and Store release conditions remain open. Final review of teaching content, pronunciation, and translations, along with distribution rights for the default dictionary and audio, also remains open. See the [third-party license review](../THIRD_PARTY_LICENSES.md) and [deferred release gates](../../HanMate_Planning_Pack_v3.0/tracking/deferred-release-gates.json). Checks requiring devices are not marked as passed unless actually run. Build, package signature, preflight, and file hashes are recorded in `manifest.json`, `release-preflight.json`, and `SHA256SUMS.txt` attached to this release.

## 日本語

HanMate 0.1.5 は Windows x64 / Android ARM64 向けの開発プレビューです。アプリのバージョンは `0.1.5`、プラットフォームのビルド番号は `7` です。無料・アプリ内課金なし。このバージョンは Microsoft Store と Google Play では配信していません。

### 今回の変更

- 設定でシステム、ライト、ダークのテーマを選び、選択中の項目を強調表示します。
- Windows のライトテーマで拼音ページのボタンが見づらくなる問題を修正しました。文字、背景、枠線はテーマに合わせて切り替わります。
- スマートフォンでは検索モード切り替えをタイトルバー中央に配置しました。検索、手書き例語、読書画面で破損データとページのライフサイクルをより安全に処理します。
- Windows の拼音と例語の操作はマウスクリックと長押しに対応し、右クリックで戻ります。

### ダウンロードとインストール

Windows は `HanMate-0.1.5-windows-x64-preview.zip` をダウンロードし、旧版を終了してから元のプログラムフォルダーに ZIP 全体を展開し、`HanMate.App.exe` を起動してください。Android の `HanMate-0.1.5-android-arm64-dev-signed.apk` は ARM64 端末用で、開発用署名を使用します。上書き更新にはインストール済みアプリと同じ署名鍵が必要です。更新前にアプリ内でバックアップしてください。署名エラーを回避するために旧版をアンインストールしないでください。`SHA256SUMS.txt` でダウンロードを確認できます。

### 検証範囲と制限

本版は開発プレビューであり、ストア承認や製品全体の受け入れを示すものではありません。Android APK は開発用署名です。正式署名、全端末回帰、ストア公開条件は未完了です。教材・発音・訳文の最終確認と、標準辞書・音声の配布権利確認も未完了です。[第三者ライセンス確認](../THIRD_PARTY_LICENSES.md)と[後続の公開条件](../../HanMate_Planning_Pack_v3.0/tracking/deferred-release-gates.json)を参照してください。実施していない端末確認は合格として扱いません。ビルド、署名、事前確認、ファイルハッシュは本リリースの添付ファイル `manifest.json`、`release-preflight.json`、`SHA256SUMS.txt` に記録します。
