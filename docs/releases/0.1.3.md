# HanMate 0.1.3 · Preview

简体中文 · English · 日本語

## 简体中文

0.1.3 是 Windows x64 / Android ARM64 开发预览版，应用版本 `0.1.3`、平台构建号 `5`。免费，无内购；Microsoft Store 与 Google Play 尚未提供此版本。

### 本版内容

- 新增同一 Wi-Fi 网络内的学习内容分享：创建房间、选择接收设备，并发送选中的词语、课文、语法或诗词。
- 接收方可先查看导入内容，再确认是否保存；导入时可选择词语分类的存放位置。
- 补充常用课文与语法内容，并改进个人分类及分享相关体验。

### 下载与安装

Windows：下载 `HanMate-0.1.3-windows-x64-preview.zip`，完整解压后运行 `HanMate.App.exe`。Android：下载 `HanMate-0.1.3-android-arm64-dev-signed.apk`，仅适用于 ARM64 设备，使用开发签名。升级前先使用应用内备份；若签名冲突，不要卸载旧版来绕过。使用 `SHA256SUMS.txt` 核对下载文件。

### 验证范围与已知限制

本版仍是开发预览，不代表商店批准或完整产品验收。Android APK 使用开发签名；正式签名、完整设备回归和商店发布条件尚未完成。教学内容、发音、译文的终审以及默认词库和音频的分发权利仍待核实；详情见[第三方许可核查](../THIRD_PARTY_LICENSES.md)及[后置发布门禁](../../HanMate_Planning_Pack_v3.0/tracking/deferred-release-gates.json)。设备未实际验证的项目不会标记为通过。构建、包签名、预检和文件哈希以本次发布资产中的 `manifest.json`、`release-preflight.json` 与 `SHA256SUMS.txt` 为准。

## English

HanMate 0.1.3 is a Windows x64 / Android ARM64 development preview. App version `0.1.3`, platform build number `5`. Free, with no in-app purchases; this version is not available through Microsoft Store or Google Play.

### What's new

- Share selected vocabulary, reading passages, grammar, and poetry over the same Wi-Fi network. Create a room and choose the receiving devices.
- Recipients can review a package before importing it and choose where incoming word categories go.
- Added common reading and grammar material, with improvements to personal categories and sharing.

### Download and install

For Windows, download `HanMate-0.1.3-windows-x64-preview.zip`, extract the complete archive, and run `HanMate.App.exe`. The Android download, `HanMate-0.1.3-android-arm64-dev-signed.apk`, targets ARM64 devices and uses a development signing key. Back up in the app before upgrading. Do not uninstall an existing Android copy to work around a signature mismatch. Verify downloads with `SHA256SUMS.txt`.

### Validation and known limitations

This remains a development preview; it does not indicate Store approval or complete product acceptance. The Android APK uses a development certificate. Production signing, full device regression, and Store release conditions remain open. Final review of teaching content, pronunciation, and translations, along with distribution rights for the default dictionary and audio, also remains open. See the [third-party license review](../THIRD_PARTY_LICENSES.md) and [deferred release gates](../../HanMate_Planning_Pack_v3.0/tracking/deferred-release-gates.json). Checks requiring devices are not marked as passed unless actually run. Build, package signature, preflight, and file hashes are recorded in `manifest.json`, `release-preflight.json`, and `SHA256SUMS.txt` attached to this release.

## 日本語

### 今回の変更

- 同じ Wi-Fi ネットワーク内で学習コンテンツを共有できます。ルームを作成し、単語・課文・文法・詩の中から選んで、受信端末へ送信できます。
- 受信側は取り込み前に内容を確認でき、受信した単語カテゴリの保存先を選べます。
- よく使う課文と文法コンテンツを追加し、個人カテゴリと共有機能を改善しました。

### ダウンロードとインストール

Windows は `HanMate-0.1.3-windows-x64-preview.zip` をダウンロードし、ZIP 全体を展開して `HanMate.App.exe` を起動してください。Android の `HanMate-0.1.3-android-arm64-dev-signed.apk` は ARM64 端末用で、開発用署名を使用します。更新前にアプリ内でバックアップしてください。署名エラーを回避するために旧版をアンインストールしないでください。`SHA256SUMS.txt` でダウンロードを確認できます。

本版は開発プレビューであり、ストア承認や製品全体の受け入れを示すものではありません。Android APK は開発用署名です。正式署名、全端末回帰、ストア公開条件は未完了です。教材・発音・訳文の最終確認と、標準辞書・音声の配布権利確認も未完了です。[第三者ライセンス確認](../THIRD_PARTY_LICENSES.md)と[後続の公開条件](../../HanMate_Planning_Pack_v3.0/tracking/deferred-release-gates.json)を参照してください。実施していない端末確認は合格として扱いません。ビルド、署名、事前確認、ファイルハッシュは本リリースの添付ファイル `manifest.json`、`release-preflight.json`、`SHA256SUMS.txt` に記録します。
