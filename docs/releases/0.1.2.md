# HanMate 0.1.2 · Preview

简体中文 · English · 日本語

## 简体中文

0.1.2 是 Windows x64 / Android ARM64 开发预览版，应用版本 `0.1.2`、平台构建号 `4`。免费，无内购；Microsoft Store 与 Google Play 尚未提供此版本。

### 本版内容

- 新增个人词语的新增和编辑，可填写释义、例句及英文/日文辅助译文，并使用自定义分类。
- 新增个人课文、语法和诗词的新增与编辑。
- 改进备份合并与恢复，对个人分类、词典收藏引用和资源状态作一致处理。
- 改进 Android 学习与收藏列表的键盘焦点名称，以及字典详情返回时的列表位置保持。

### 下载与安装

Windows：下载 `HanMate-0.1.2-windows-x64-preview.zip`，完整解压后运行 `HanMate.App.exe`。Android：下载 `HanMate-0.1.2-android-arm64-dev-signed.apk`，仅适用于 ARM64 设备，使用原开发签名。升级前先使用应用内备份；若签名冲突，不要卸载旧版来绕过。使用 `SHA256SUMS.txt` 核对下载文件。

### 验证范围与已知限制

本版仍是开发预览，不代表商店批准或完整产品验收。Android APK 使用开发签名；正式签名、完整设备回归和商店发布条件尚未完成。教学内容、发音、译文的终审以及默认词库和音频的分发权利仍待核实；详情见[第三方许可核查](../THIRD_PARTY_LICENSES.md)及[后置发布门禁](../../HanMate_Planning_Pack_v3.0/tracking/deferred-release-gates.json)。具体构建、包签名、预检、文件大小和哈希以本次候选包中的 `manifest.json`、`release-preflight.json` 与 `SHA256SUMS.txt` 为准。设备未实际验证的项目不会标记为通过。

## English

HanMate 0.1.2 is a Windows x64 / Android ARM64 development preview. App version `0.1.2`, platform build number `4`. Free, with no in-app purchases; this version is not available through Microsoft Store or Google Play.

### What's new

- Create and edit personal vocabulary with definitions, examples, English/Japanese translations, and custom categories.
- Create and edit personal passages, grammar entries, and poems.
- Improve backup merge and restore handling for personal categories, dictionary bookmark references, and resource state.
- Improve named keyboard focus in Android learning and favorites lists, and preserve list position when returning from dictionary details.

### Downloads and installation

For Windows, download `HanMate-0.1.2-windows-x64-preview.zip`, extract the complete archive, and run `HanMate.App.exe`. The Android download, `HanMate-0.1.2-android-arm64-dev-signed.apk`, targets ARM64 devices and uses the existing development signing key. Back up in the app before upgrading. Do not uninstall an existing Android copy to work around a signature mismatch. Verify downloads with `SHA256SUMS.txt`.

### Validation and known limits

This remains a development preview; it does not indicate Store approval or complete product acceptance. The Android APK uses a development certificate. Production signing, full device regression, and Store release conditions remain open. Final review of teaching content, pronunciation, and translations, along with distribution rights for the default dictionary and audio, also remains open. See the [third-party license review](../THIRD_PARTY_LICENSES.md) and [deferred release gates](../../HanMate_Planning_Pack_v3.0/tracking/deferred-release-gates.json). Build, package signature, preflight, file size, and hashes are recorded in the candidate's `manifest.json`, `release-preflight.json`, and `SHA256SUMS.txt`. Checks requiring devices are not marked as passed unless actually run.
