## 待填的日文介绍

HanMate は、ピンイン、単語、文法、課文、詩、辞書と読み上げをまとめた中国語学習アプリです。無料・広告なし・アプリ内課金なし。

日常語、呼び方、挨拶、数字、量詞、長さ、重さ、調理器具、生活用品などのカテゴリから単語を学べます。単語をタップすると読み上げ、長押しすると収録済みの説明や例文を表示します。課文・詩の題名、作者、本文の短い区切りにもピンインと読み上げを用意しています。

ローカル辞書の検索、手書き入力、お気に入りのフォルダー整理、自分の文章や録音の保存に対応します。画面は簡体字中国語・英語・日本語に切り替えられ、収録されている内容には補助訳文を表示します。

Melo と Kokoro の音声は端末内で合成し、システム音声も選べます。主な学習機能はオフラインで利用でき、任意のリソースダウンロードにはインターネット接続が必要です。マイクは録音を選んだ場合に使用し、アカウント登録は不要です。

0.1.0 は初期プレビュー版です。読み上げの品質と初回読み込み時間は端末や文章によって異なります。更新前にローカルデータをバックアップしてください。子どもが録音・インポート・共有・バックアップを使う場合は、大人のサポートをおすすめします。

短い説明：ピンイン、単語、文法、課文、詩、辞書と読み上げで中国語をオフライン学習。無料・広告なし・アプリ内課金なし。

## runFullTrust / 認証担当者向け説明草案

HanMate is a .NET MAUI / WinUI desktop application. The runFullTrust capability is required for its desktop process and local SQLite storage, user-selected file import/export and backup, audio playback/recording, and native on-device speech inference. It does not request administrator elevation or install a background Windows service. No account is required. Microphone access is used for user-initiated recording. Melo and Kokoro synthesis run locally; optional resource downloads require a network connection.
