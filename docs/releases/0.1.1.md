# HanMate 0.1.1 · Preview

简体中文 · English · 日本語

## 简体中文

0.1.1 是 Windows x64 / Android ARM64 的开发预览更新，应用版本 `0.1.1`、构建号 `3`。免费，无内购。Google Play 与 Microsoft Store 的上架状态以各商店页面为准。

- 拼音例字、例词与其他词语共用朗读逻辑：已有匹配录音优先，缺少录音时使用设置中选择的 Melo、Kokoro 或系统声音。
- 无匹配录音的独立拼音示范仅在选中 Melo 时合成；选中 Kokoro 或系统声音时会提示不可用，不会切换音源或朗读拉丁字母。
- 移除旧的拼音独立 AI 优先选项，统一三语设置说明。
- HanMate 自有源码与原创文档采用 MIT；安装包补充 MIT、字典上游许可原文、字体署名和第三方许可说明。

### 安装

Windows：下载 `HanMate-0.1.1-windows-x64-preview.zip`，完整解压后运行 `HanMate.App.exe`。Android：下载 `HanMate-0.1.1-android-arm64-dev-signed.apk`，适用于 ARM64 设备，仍使用原开发签名。升级前备份应用内资料；签名冲突时不要直接卸载旧版。`SHA256SUMS.txt` 用于核验下载完整性。

### 验证与边界

实际测试、构建和哈希结果以本次发布记录为准；本地构建清单为 `manifest.json`。完整真机验收与正式发行签名尚未完成。MIT 仅覆盖 HanMate 自有源码与原创文档，不重新许可随包材料，也不对尚无已核实许可说明的素材作许可声明；未解决的来源及分发义务见[许可核查](../THIRD_PARTY_LICENSES.md)。

## English

Development preview update for Windows x64 and Android ARM64. App version `0.1.1`, build `3`. Free, with no in-app purchases. Check the store pages for the current Google Play and Microsoft Store availability.

- Pinyin examples now share the vocabulary speech path: matching recordings take priority, then the selected Melo, Kokoro or system voice.
- Standalone pinyin demonstrations without recordings are synthesized only when Melo is selected. Kokoro and system speech report them unavailable; playback does not switch voices or read Latin letters.
- Removed the separate legacy pinyin AI preference and updated the Chinese, English and Japanese settings text.
- Original HanMate code and documentation use MIT. Bundles now include the project license, upstream dictionary license text, font attribution and third-party license notes.

Extract the complete Windows ZIP and run `HanMate.App.exe`. The Android APK is ARM64-only and uses the existing development certificate. Back up before upgrading; do not uninstall to bypass a signature mismatch. Use `SHA256SUMS.txt` to verify downloads.

Actual test, build and integrity results are recorded in this release's verification notes; `manifest.json` is a local build record. Full device acceptance and production signing remain outstanding. MIT applies only to HanMate-owned source and original documentation; it does not relicense bundled material or assert a license for material without a verified notice. Unresolved provenance and distribution obligations are documented in the [license review](../THIRD_PARTY_LICENSES.md).

## 日本語

Windows x64 / Android ARM64 向け開発プレビュー更新です。アプリ `0.1.1`、ビルド番号 `3`。無料・アプリ内課金なし。Google Play と Microsoft Store の公開状況は各ストアのページで確認してください。

- ピンインの例字・例語を単語の読み上げ処理に統一しました。一致する録音を優先し、録音がなければ選択した Melo・Kokoro・システム音声を使用します。
- 録音のない単独ピンインの発音例は、Melo を選択した場合のみ合成します。Kokoro またはシステム音声では利用不可と表示し、別の音声への切り替えやラテン文字の読み上げは行いません。
- 旧ピンイン専用 AI 優先設定を削除し、三言語の説明を更新しました。
- 独自コードとオリジナル文書に MIT を適用し、配布物にプロジェクトのライセンス、辞書の上流ライセンス、フォントのクレジット、第三者素材の確認記録を追加しました。

Windows ZIP は全体を展開して `HanMate.App.exe` を実行してください。Android APK は ARM64 用で、従来の開発用署名を使用します。更新前にバックアップし、署名エラーを回避するためのアンインストールは避けてください。整合性の確認には `SHA256SUMS.txt` を使用できます。

テスト・ビルド・整合性検証の結果は今回の公開記録に記載します。`manifest.json` はローカルのビルド記録です。実機での完全な受け入れ検証と正式署名は未完了です。MIT は HanMate 独自のソースコードとオリジナル文書にのみ適用し、同梱素材を再ライセンスしたり、確認済みの許諾表示がない素材についてライセンスを主張したりしません。未解決の権利と配布義務は[確認記録](../THIRD_PARTY_LICENSES.md)に記載しています。
